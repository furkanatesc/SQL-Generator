# Arşiv — Eski Sürüm-Tasarım Notları

Buradaki `v1–v4` dosyaları, projenin daha erken bir aşamasında kullanılan
**sürüm/olgunluk (v) tabanlı** tasarım notlarıdır. Yol haritası artık
**Phase → Sprint → PR** ekseninde ilerlediği için bu dosyalar **arşive** alındı;
güncel plan değildir, yalnızca geçmiş tasarım gerekçeleri için referanstır.

Güncel kaynaklar:
- Durum / yol haritası: `../../ROADMAP.md`
- Planlanan sprintler: `../PLANNED-SPRINTS.md`
- Tamamlanan sprint/PR günlüğü: `../SPRINT-PR-LOG.md`

Arşivdeki dosyalar:
- `v1-production-plan.md` — Controlled Production Baseline (v1.0.0'da yayınlandı)
- `v2-feedback-loop.md` — Feedback/öğrenen sistem tasarımı (planda yok; fikir olarak `PLANNED-SPRINTS.md` → "Önerilen Ek Sprintler")
- `v3-graphrag-ppr.md` — GraphRAG/PPR tasarım notları (kısmen Phase 9–10'a karşılık gelir)
- `v4-enterprise.md` — Enterprise platform tasarım notları (kısmen Phase 7–8, 14'e karşılık gelir)

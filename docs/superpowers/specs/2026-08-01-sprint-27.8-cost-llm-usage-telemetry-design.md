# Sprint 27.8 — Cost & LLM Usage Telemetry — Tasarım Spec'i (SDD)

**Tarih:** 2026-08-01 · **Phase:** 8 (Observability & Debuggability) · **Branch:** `sprint-27.8-cost-llm-usage-telemetry`

## Amaç

Bir zaman penceresindeki `end_to_end` trace'lerin **GENERATION span**'lerinden LLM
kullanımını (request sayısı, prompt/completion/total token, latency, finish_reason)
toplayan ve **konfigüre edilebilir fiyat tablosuyla tahmini maliyet** üreten, yan
etkisiz, versiyonlu `GET /api/debug/llm-usage`. Yeni pipeline enstrümantasyonu
GEREKMEZ — kullanım verisi 27.1w'den beri her trace'in GENERATION span'inde
(`provider_id/model_id/finish_reason/prompt_tokens/completion_tokens/total_tokens` +
span `duration_ms`) zaten yakalanıyor. 27.8 yalnızca aggregation + fiyatlandırma
katmanıdır.

## Saf hesaplama sözleşmesi

`compute_llm_usage(trace_items, window, price_table, bucket)`:

- **Girdi:** `trace_items = [(created_at, payload), ...]`; `window` (frozen
  `UsageWindow`); `price_table` (`{model_id: {"input_per_1m": float,
  "output_per_1m": float}}`); `bucket ∈ {"hour","day"}`.
- Her payload'ın `spans` listesinde `stage == "generation"` olan span aranır. Span yoksa
  ya da `status == "skipped"` ise o trace kullanım olayı SAYILMAZ (LLM koşmamış). Koşan
  bir generation olayının statüsü `"ok"`/`"warning"`/`"error"` olabilir — hata dalı da
  bir LLM isteğidir (token tüketmiş olabilir), sayılır; tokenlar None ise atlanır.
- Bir "generation olayı" = koşan GENERATION span'i olan trace (trace başına **bir**
  olay; bkz. Bilinen Sınır). **Alanlar span dict'inin `detail` alt-sözlüğünden okunur**
  (doğrulanmış span payload şekli: `{"stage","status","duration_ms","detail_kind",
  "detail":{"provider_id","model_id","finish_reason","prompt_sha256","output_sha256",
  "prompt_tokens","completion_tokens","total_tokens"},"attributes"}`; enum'lar `.value`
  ile küçük harf serilenir). `detail` None olabilir → tokenlar/model None sayılır.
- **Token toplamları:** `None` atlanır; sayısal (int, bool değil) değerler toplanır.
- **Maliyet (model başına):** `prompt_tokens/1e6 × input_per_1m +
  completion_tokens/1e6 × output_per_1m`, `round(..., 6)`. Model `price_table`'da yoksa
  o modelin `estimated_cost = None`; tokenları yine sayılır; model_id `models_missing_price`'a
  eklenir. **Toplam `estimated_cost` = fiyatlı modellerin maliyet toplamı** (fiyatlı
  hiç yoksa `0.0`). `totals.unpriced_request_count` = model_id'si `price_table`'da
  bulunmayan generation olaylarının sayısı (maliyetin ne kadarının kapsanmadığını
  gösterir; şeffaflık).
- **Latency:** generation `duration_ms` değerleri (None atlanır) üzerinden nearest-rank
  p50/p95/p99 (`ceil(p*n)`), `count` ile.
- **finish_reason dağılımı:** ham string sayaçları (None → sayılmaz), SIRALI.
- **Zaman-serisi:** `created_at` UTC'ye floor'lanır (hour: dakika/saniye sıfır; day:
  saat de sıfır), bucket başına `request_count`/`total_tokens`/`estimated_cost`. Bucket'lar
  ARTAN sıralı; `MAX_USAGE_BUCKETS = 500` üstünde en-yeni-N tutulur ve `timeseries_truncated=True`.
- **Determinizm:** `datetime.now()` ASLA; aynı girdi → aynı `to_payload()`; sıralı
  sözlükler; nearest-rank.

### Frozen record'lar (contract.py)

- `UsageWindow(created_after, created_before, bucket, trace_count, generation_count,
  truncated, scan_cap, timeseries_truncated=False)`
- `UsageTotals(request_count, prompt_tokens, completion_tokens, total_tokens,
  estimated_cost, unpriced_request_count)`
- `ModelUsage(model_id, request_count, prompt_tokens, completion_tokens, total_tokens,
  estimated_cost)` — `estimated_cost` Optional
- `ProviderUsage(provider_id, request_count, prompt_tokens, completion_tokens,
  total_tokens, estimated_cost)`
- `LatencyStats(count, p50, p95, p99)`
- `UsageBucket(bucket_start, request_count, total_tokens, estimated_cost)`
- `PricingInfo(models_priced: Tuple[str,...], models_missing_price: Tuple[str,...])`
- `LLMUsageReport(version, currency, window, totals, by_model, by_provider, latency_ms,
  finish_reasons, timeseries, pricing)`

`by_model`/`by_provider` sıralaması: `total_tokens` AZALAN, eşitlikte `model_id`/
`provider_id` ARTAN (determinist).

## `llm_pricing` config formatı

`configs` DB tablosunda `llm_pricing` anahtarı, JSON (mevcut `POST /api/configs/{key}`
ile ayarlanır):

```jsonc
{ "currency": "USD",
  "models": { "llama-3.3-nemotron-super-49b-v1.5": { "input_per_1m": 3.0, "output_per_1m": 3.0 } } }
```

Saf `parse_price_table(raw_json_str_or_none)` (adaptörde/pure helper):
- `None`/boş/geçersiz JSON → `("USD", {})` (cost'lar null, `models_missing_price` dolu).
- `currency` yoksa `"USD"`.
- `models` içindeki her giriş `{input_per_1m, output_per_1m}` sayısal değilse o model
  atlanır (fiyatsız sayılır).

## Hata yönetimi

- Trace store hatası → propagate (yutulmaz), 27.6/27.7 adaptörleriyle tutarlı.
- Geçersiz `llm_pricing` JSON → sessiz boş tablo (endpoint çalışır, cost'lar null,

- `bucket` geçersiz → FastAPI 422 (Literal). Debug kapalı → 404. API key yok → 403.

## Bilinen sınırlar (TECH-DEBT §9 — sessiz düşürme yok)

1. **Retry token eksik-sayımı.** `end_to_end` trace **tek** GENERATION span taşır;
   writer-critic retry döngüsündeki birden çok LLM çağrısından yalnız yakalanan (son)
   generation'ın token'ları payload'a iner. Retry'lı işlerde maliyet **eksik tahmin**
   edilir. Bu trace-contract'ın yapısal sınırı; per-attempt token yakalama ayrı iş
   (kapsam dışı, gelecek trace-contract revizyonu).
2. **`scan_cap` üstü alt-küme.** Pencere `scan_cap`'i aşarsa kullanım/maliyet çekilen
   alt küme üzerinden; `truncated=true` işaretlenir. Tam doğruluk DB-side aggregation
   ister (27.6 §7, 27.7 §8 ile aynı kök).
3. **Zaman-serisi zero-fill yok.** Boş bucket'lar atlanır; tüketici seyrek bucket'ları
   kendi doldurur.
4. **Küçük saf-helper tekrarı.** nearest-rank percentile ve timestamp-floor helper'ları
   metrics/dashboard'da da var; leaf'i bağımsız tutmak için 27.8 kendi kopyasını taşır
   (kodtabanı deseniyle tutarlı).

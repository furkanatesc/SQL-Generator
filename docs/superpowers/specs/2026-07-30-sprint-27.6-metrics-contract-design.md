## 1. Amaç

Bir zaman penceresindeki `end_to_end` trace'lerini toplayıp **makine-okur, versiyonlu
bir metrik raporu** üretmek: hacim & sonuç dağılımı, hata taksonomisi, gecikme
percentile'ları ve aşama-bazında kırılım. Tek JSON envelope, debug-gated `GET
/api/debug/metrics`.

Cevapladığı somut sorular:
- Bu pencerede kaç koşu vardı, ne kadarı başarılı (`terminal_status`)?
- En sık hangi hata kodları / kategorileri görülüyor (27.2 registry)?
- Uçtan uca gecikme dağılımı ne (p50/p95/p99)?
- Hangi aşama (intent/retrieval/generation/security/validation) ne sıklıkta hata/skip veriyor?

Metrikler **doğası gereği hassas değildir** (yalnız sayımlar + kapalı registry hata
kodları + süreler); ham içerik taşımaz, bu yüzden redaksiyon **gerekmez**. Hesaplama
**yan etkisizdir**: hiçbir şey yazılmaz, trace emit edilmez, LLM'e gidilmez.

## 3. Tasarım

### 3.1 Saf yaprak paket — `backend/app/metrics/`

İzinli import yüzeyi: **stdlib + `app.errors`** (`category_of`, `ErrorCategory`,
`UnknownErrorCodeError` — 27.4'te ölçülerek izinli kılındı: yalnız kendi alt modüllerini
çeker, sıfır driver/framework). Yasak: `pydantic`, `fastapi`, `app.database`,
**`app.trace.*`**, DB driver. Purity guard testi **taze bir alt süreçte** kilitler
(27.4 dersi: aynı süreçte `sys.modules` cache'i ölçümü maskeler).

Modüller:
- `contract.py` — frozen record'lar + `to_payload()`:
  - `MetricsReport(version, window, outcome, errors, latency_ms, stages)`
  - `MetricsWindow(created_after, created_before, dialect, trace_count, truncated, scan_cap)`
  - `OutcomeMetrics(total, terminal_status: dict, success_rate: Optional[float])`
  - `ErrorMetrics(by_code: dict, by_category: dict)`
  - `LatencyMetrics(count, p50, p95, p99, min, max, mean)` (hepsi `Optional` — boşta `None`)
  - `StageMetrics` = `dict[str, dict[str,int]]` (stage → status → sayı)
  - `to_payload()` JSON-safe, determinist; sözlük anahtarları **sıralı**.
- `compute.py` — saf `compute_metrics(payloads: list[Mapping], window: MetricsWindow) -> MetricsReport`.

**Aggregation kuralları:**
- **outcome:** `total = len(payloads)`; her payload'ın `terminal_status`'u sayılır
  (`completed/failed/blocked/rejected`; beklenmeyen değer olduğu gibi kova olur);
  `success_rate = round(completed/total, 4)` — `total==0` ise `None` (0/0 yok).
- **errors:** her payload'ın `spans`'inde `status=="error"` olan span'in kodu (birden
  fazla olabilir) asamaya göre farklı yerden okunur: INTENT/RETRIEVAL için
  `attributes.reason_code`; bu yoksa typed span `detail`'ından — VALIDATION için
  `detail.issues[].reason_code` (her issue), SECURITY için `detail.checks[]` içinde
  `outcome`'u deny kümesinde (`{"denied","error"}`) olan her check'in `reason_code`'u.
  (GENERATION hatalarının kodu yok — meşru şekilde sayılmaz.) Deny kümesi
  `app.trace.end_to_end_trace_builders::_DENY_OUTCOMES`'tan **MIRROR'lanmış** yerel bir
  sabittir (saf katman `app.trace` import edemez). Bulunan her kod `by_code`'a sayılır;
  `category_of(code)` ile `by_category`'ye eşlenir; `UnknownErrorCodeError` **yutulmadan**
  `"unknown"` kovasına düşer. `ErrorCategory` sınırda `.value` (plain str) taşınır.
- **latency_ms:** `total_duration_ms` toplanır (`None` atlanır); `count`, `min`, `max`,
  `mean` (round 2), ve **nearest-rank** `p50/p95/p99`. Boş liste → hepsi `None`, `count=0`.
- **stages:** sabit stage listesi (intent/retrieval/generation/security/validation) için,
  o stage span'i olan payload'larda span `status` dağılımı (ok/error/skipped/warning) sayılır.

Determinizm: nearest-rank percentile (sıralı liste + `ceil(p*n)` indeksi) her zaman aynı
girdi için aynı çıktı; tüm sözlükler `to_payload()`'ta sıralı serilenir.

### 3.2 Kirli adaptör — `backend/app/metrics_service.py`

27.4/27.5 desenini izler; DB yok, **RAW trace store**'a dokunur (redaksiyon YOK — metrikler
hassas değil).

```
compute_metrics_for_window(*, trace_store, created_after=None, created_before=None,
                           dialect=None, scan_cap=10000) -> dict   # to_payload çıktısı
```
Akış:
1. `TraceQuery(trace_type="end_to_end", created_after, created_before, dialect,
   limit=scan_cap + 1)` — `+1` truncation tespiti için.
2. `rows = trace_store.list_traces(query)`. Store hatası **YUTULMAZ** → yukarı çıkar (§3.4).
3. `truncated = len(rows) > scan_cap`; `rows = rows[:scan_cap]`.
4. Payload çıkarımı: `record.payload` (dict) ya da `getattr(record, "payload")` — 27.5
   `bundle_service` ile aynı dict/obj record kabulü.
5. `window = MetricsWindow(created_after, created_before, dialect, trace_count=len(payloads),
   truncated, scan_cap)`.
6. `return compute_metrics(payloads, window).to_payload()`.

`SCAN_CAP = 10000` modül sabiti.

### 3.3 Router — `backend/app/api/metrics_api.py`

`debug_traces.py`/`debug_replay.py` ile simetrik: kendi `APIRouter`'ı, `Depends(verify_api_key)`,
`ensure_debug_enabled()` (kapalıyken 404, ağır iş öncesi), `get_trace_store` bağımlılığı.

```
GET /api/debug/metrics?created_after=&created_before=&dialect=  -> MetricsEnvelopeResponse
```
`{"status":"success","metrics":{...}}`, 200. Sınırda plain str/dict (enum yok).

### 3.4 Hata yönetimi (27.4/27.5 dürüstlük deseni)
- Debug kapalı → **404** (en başta).
- **Boş pencere** (trace yok) → **200**, sıfırlarla: `total=0`, `success_rate=null`, boş
  dağılımlar, `latency` `None`'lar. Bu bir hata DEĞİL.
- **Trace store hatası** → **yutulmaz**, yukarı çıkar → 500. Bir gözlemlenebilirlik aracı
  hatayı gizlerse yanlış sinyal verir.
- **truncation** → sessizce kesme YOK: `window.truncated=true` + `trace_count` ile açıkça
  işaretlenir; metrikler çekilen alt küme üzerinden hesaplanır.
- Geçersiz tarih parametreleri → mevcut `debug_traces` davranışıyla aynı (TraceQuery
  fromisoformat'ı deneyip ValueError'da yok sayar); metrics endpoint parametreleri aynen geçirir.

## 4. Test

- **Saf birim** (`tests/metrics/`):
  - `compute_metrics` **determinizmi**: aynı girdi → byte-özdeş `to_payload()`.
  - **outcome:** terminal_status dağılımı + `success_rate` (total=0 → `null`).
  - **errors:** `by_code` ERROR span `reason_code`'undan; `by_category` `category_of` ile;
    **bilinmeyen kod → `"unknown"`** kovası.
  - **latency:** **bilinen liste → bilinen p50/p95/p99** (nearest-rank), `None` süre atlanır,
    boş → `None`/`count=0`.
  - **stages:** stage span status dağılımı; eksik stage span atlanır.
  - Boş girdi → tüm sıfır/None; `to_payload` JSON-safe.
- **Purity guard:** `app.metrics` taze alt süreçte yalnız stdlib + `app.errors` import eder.
- **Adaptör** (`metrics_service`): `truncated` bayrağı (>cap → true, trace_count=cap);
  store-hatası yukarı çıkar (yutulmaz); window meta doğru; dict/obj record.
- **Router / sözleşme:** debug-off→404; 403 key-yok; happy-path 200 envelope; **boş pencere→200**;
  `debug_replay`/`debug_traces` sözleşme testleriyle simetrik.
- **Contract snapshot:** `openapi_snapshot.json` (+ gerekiyorsa `status_contract_snapshot.json`)
  yeni route için **bilinçli** güncellenir; diff yalnız eklenen endpoint (blind blessing değil).

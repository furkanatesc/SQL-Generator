# Sprint 27.7 — Admin Observability Dashboard Backend (design)

**Tarih:** 2026-07-31
**Faz:** 8 (Observability & Debuggability)
**Öncül:** Sprint 27.6 (Metrics Contract, PR #144 merged, main @ `96a64e1`).
Gözlemlenebilirlik katmanı artık `end_to_end` trace (27.1w), tek registry hata kodları
(27.2), feedback yakalama (27.3), replay (27.4), tek-job bundle export (27.5) ve
pencere-bazlı aggregate metrikleri (27.6) sağlıyor. Bu sprint bunları **tek bir admin
gözlemlenebilirlik dashboard'una** toplar: zaman-serisi trendleri + kompozit paneller.

## 1. Amaç

Bir zaman penceresi için, bir admin dashboard'unun render edeceği **tek kompozit JSON
payload** üretmek: 27.6 metrik snapshot'ı + zaman-serisi trend + top hatalar + feedback
özeti + son aktivite. Debug-gated `GET /api/debug/dashboard`, **yan etkisiz**.

27.6'nın açıkça 27.7'ye ertelediği **zaman-serisi/bucketing** burada gerçekleşir.

Cevapladığı somut sorular:
- Metrikler zaman içinde nasıl seyrediyor (bucket bazında total/başarı/hata/p95)?
- Bu pencerede en sık hangi hata kodları (top-N)?
- Kullanıcı feedback'i ne durumda (verdict/category dağılımı)?
- Son ne oldu (son N koşu)?

Dashboard verisi **hassas değildir** (sayımlar + kapalı registry kodları + süreler +
feedback verdict/category); ham içerik taşımaz → redaksiyon **gerekmez**. Hesaplama
**yan etkisizdir**: yazma yok, trace emit yok, LLM yok.

## 3. Tasarım

### 3.1 Saf yaprak paket — `backend/app/dashboard/`

İzinli import yüzeyi: **stdlib + `app.errors` + `app.metrics`**. `app.metrics` 27.6'da saf
leaf olarak kanıtlandı (yalnız stdlib + app.errors); `compute_metrics` ve contract tipleri
oradan gelir. Yasak: `pydantic`, `fastapi`, `app.database`, **`app.trace.*`**, DB driver.
Purity guard **taze bir alt süreçte** kilitler (27.4 dersi).

Modüller:
- `contract.py` — frozen record'lar + `to_payload()`:
  - `DashboardReport(version, window, metrics, timeseries, top_errors, feedback, recent_activity)`
  - `DashboardWindow(created_after, created_before, dialect, trace_count, truncated, scan_cap, bucket, timeseries_truncated)`
  - `TimeseriesBucket(bucket_start, total, success_rate, error_count, p95_ms)`
  - `TopError(code, category, count)`
  - `FeedbackSummary(total, by_verdict: dict, by_category: dict)`
  - `RecentTrace(job_id, trace_id, terminal_status, dialect, total_duration_ms, created_at)`
  - `metrics` alanı 27.6 `MetricsReport.to_payload()` (plain dict) taşır.
  - `to_payload()` JSON-safe, determinist; sözlük anahtarları **sıralı**, listeler açık sıralı.
- `compose.py` — saf fonksiyonlar (aşağıda) + `compose_dashboard(...)`.

**Saf aggregation kuralları:**
- **timeseries** — `bucket_timeseries(trace_items, bucket_kind)`:
  - Her item `(created_at: datetime, payload: dict)`. `created_at` UTC'de `hour`→saat başına,
    `day`→gün başına **floor**'lanır (`datetime.now()` YOK — mevcut damga floor'lanır → saf).
  - Her bucket: `total`, `success_rate=round(completed/total,4)` (completed = terminal_status
    "completed"), `error_count` (terminal_status ∈ {failed,blocked,rejected}), `p95_ms`
    (bucket içi `total_duration_ms`'lerin **nearest-rank** p95'i; hiç süre yoksa `None`).
  - `bucket_start` ISO string; **artan** sıralı; yalnız **dolu** bucket'lar.
  - Üst sınır `MAX_TIMESERIES_BUCKETS = 500`: bucket sayısı aşarsa **en yeni 500** tutulur ve
    `window.timeseries_truncated=true` (sessiz kesme yok).
- **top_errors** — `top_errors(metrics_payload, top_n)`: metrik snapshot'ının
  `errors.by_code`'undan sayıya göre azalan (eşitlikte koda göre artan — determinist) ilk
  `top_n`; her biri `{code, category, count}`, `category` `category_of(code).value`
  (bilinmeyen → `"unknown"`).
- **feedback** — `summarize_feedback(rows)`: `total=len(rows)`; `by_verdict` (verdict sayımı);
  `by_category` (None/boş kategori atlanır). Sözlükler sıralı.
- **recent_activity** — `shape_recent(trace_items, recent_limit)`: DESC sıralı `trace_items`'in
  ilk `recent_limit`'i → `RecentTrace(job_id, trace_id, terminal_status, dialect,
  total_duration_ms, created_at_iso)`. Alan kaynağı: `created_at`/`trace_id`/`job_id`
  record'dan, geri kalan payload'dan.
- **compose_dashboard(*, trace_items, feedback_rows, window_base, bucket, top_n, recent_limit)**:
  `window_base` adaptörün kurduğu kısmi `DashboardWindow`'dur (`timeseries_truncated=False`).
  `metrics = compute_metrics([p for _,p in trace_items], metrics_window)` (metrics_window
  window_base alanlarından türetilir) → `bucket_timeseries` `(buckets, truncated_flag)` döner →
  son `DashboardWindow` `dataclasses.replace(window_base, timeseries_truncated=truncated_flag)`
  ile kurulur → dört bölüm + window → `DashboardReport`. Determinizm: aynı girdi → aynı `to_payload()`.

### 3.2 Kirli adaptör — `backend/app/dashboard_service.py`

27.6 `metrics_service` desenini izler; RAW trace store + `list_feedback`. Redaksiyon YOK.

```
build_dashboard(*, trace_store, created_after=None, created_before=None, dialect=None,
                bucket="day", top_n=10, recent_limit=20, scan_cap=SCAN_CAP) -> dict
```
Akış:
1. `TraceQuery(trace_type="end_to_end", created_after, created_before, dialect,
   limit=scan_cap+1)` → `rows = trace_store.list_traces(query)` (hata **yutulmaz**).
2. `truncated = len(rows) > scan_cap`; `rows = rows[:scan_cap]`.
3. `trace_items = [(r.created_at / r["created_at"], payload) ...]` — 27.5/27.6 dict/obj
   record kabulü; created_at ve payload birlikte çıkarılır.
4. `feedback_rows = list_feedback(created_after=..., created_before=..., limit=scan_cap)`
   (DB hatası **yutulmaz**).
5. `window` kurulur; `compose_dashboard(...)` çağrılır; `.to_payload()` döndürülür.

`SCAN_CAP = 10000` modül sabiti (27.6 ile aynı değer; ayrı sabit).

### 3.3 `database.py` — `list_feedback`

```
list_feedback(created_after: Optional[str]=None, created_before: Optional[str]=None,
              limit: int = 10000) -> list[dict]
```
`feedback` tablosundan `created_at` aralığına göre `ORDER BY created_at DESC LIMIT ?`
satır sözlükleri döndürür. `create_feedback` gibi ince persister; taksonomi import etmez.

### 3.4 Router — `backend/app/api/dashboard_api.py`

`metrics_api.py`/`debug_traces.py` ile simetrik: kendi `APIRouter`'ı, `Depends(verify_api_key)`,
`ensure_debug_enabled()` (kapalıyken 404), `get_trace_store` bağımlılığı.

```
GET /api/debug/dashboard?created_after=&created_before=&dialect=&bucket=day&top_n=10&recent_limit=20
  -> DashboardEnvelopeResponse
```
- `bucket`: `Query(default="day")`, `hour|day` dışında → **422** (FastAPI `Literal`/pattern).
- `top_n`: `Query(default=10, ge=1, le=100)`; `recent_limit`: `Query(default=20, ge=1, le=100)`.
- `{"status":"success","dashboard":{...}}`, 200. Sınırda plain str/dict (enum yok).

### 3.5 Hata yönetimi (27.4–27.6 dürüstlük deseni)
- Debug kapalı → **404** (en başta).
- **Boş pencere** → **200**, boş bölümlerle: metrics sıfırları, `timeseries: []`, `top_errors: []`,
  `feedback: {total:0,...}`, `recent_activity: []`. Hata DEĞİL.
- **Trace store / feedback DB hatası** → **yutulmaz**, yukarı çıkar → 500.
- **Sessiz kesme yok:** trace fetch cap'i → `window.truncated`; bucket cap'i → `window.timeseries_truncated`.

## 4. Test

- **Saf birimler** (`tests/dashboard/`):
  - `bucket_timeseries`: **bilinen created_at listesi → bilinen bucket'lar** (hour vs day floor);
    per-bucket `total`/`success_rate`/`error_count`/`p95_ms` (nearest-rank); artan sıralı; sparse
    (dolu bucket'lar); `MAX_TIMESERIES_BUCKETS` aşımında `timeseries_truncated` + en-yeni tutma.
  - `top_errors`: sayıya göre azalan + eşitlikte kod artan; `top_n` kesme; kategori eşlemesi
    (bilinmeyen → "unknown").
  - `summarize_feedback`: verdict/category sayımı; None kategori atlanır; boş → sıfırlar.
  - `shape_recent`: alanlar + `recent_limit`; DESC korunur.
  - `compose_dashboard`: kompozisyon + **determinizm** (aynı girdi → aynı payload); boş girdi → boş bölümler.
  - `to_payload` JSON-safe.
- **Purity guard:** `app.dashboard` taze alt süreçte yalnız stdlib + `app.errors` + `app.metrics` import eder.
- **Adaptör** (`dashboard_service`): tek trace fetch üç bölümü besler; `list_feedback` wiring;
  store-hatası + DB-hatası yukarı çıkar (yutulmaz); `truncated` bayrağı; dict/obj record.
- **DB** (`list_feedback`): pencere filtresi (created_after/before) + `ORDER BY created_at DESC` +
  `LIMIT`; boş → `[]`.
- **Router / sözleşme:** debug-off→404; 403 key-yok; happy-path 200 envelope; **boş pencere→200**;
  `bucket` validasyonu (geçersiz→422); `metrics_api`/`debug_traces` testleriyle simetrik.
- **Contract snapshot:** `openapi_snapshot.json` (+ gerekiyorsa `schema_contract_snapshot.json`)

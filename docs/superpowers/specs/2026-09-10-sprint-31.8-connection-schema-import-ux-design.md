# Sprint 31.8 — Connection Onboarding / Schema Import UX (Design Spec)

> Frontend sprint (Vue 3). No pytest/CI — verify via `npm run build`.
> Phase 12'nin SON frontend sprint'i. Kullanıcı: soru sorma, kapsam kararını kendin ver.

## 1. Problem / Brainstorm (karar)
Şema import akışı `SchemaManager.vue::loadSchema` = config'ten hedef DB'yi okur + `getSchema()`/
`refreshSchema()` ("Önbelleği Yenile" butonu) çağırır. İki UX boşluğu:
1. **Hata sessizce yutuluyor** — `loadSchema` catch'i yalnız `console.error`; backend kapalı / bağlantı
   hatalı / refresh başarısızsa kullanıcı hiçbir sinyal almaz, `schema` null kalır.
2. **Hata ≠ boş şema ayrımı yok** — tek fallback ("Veritabanından şema bilgisi çekilemedi…") hem gerçek
   bağlantı hatasını hem "bağlandı ama 0 tablo" durumunu aynı gösterir; **retry butonu yok**.

**Karar (kapsam):** 31.8 = **schema import/refresh UX sertleştirmesi** — `loadSchema` hatasını yakala
(`schemaError` ref), **hata durumu** (kırmızı, hata mesajı + "Tekrar dene" retry) ile **boş durumu**
(bağlandı ama 0 tablo, onboarding ipucu) ayır. Mevcut config-driven hedef-DB + refresh akışını kullanır;
backend değişmez. Yeni bir connection CRUD onboarding ekranı (30.2 `/api/v1/connections`) **kapsam dışı**
(persistent connection UI + secret akışı büyük/güvenlik-hassas; §28). Dar, düşük-risk, Phase 12'yi kapatır.

## 2. Design
`SchemaManager.vue` (tek dosya):
- `const schemaError = ref<string | null>(null);` (loading yanına).
- `loadSchema`: başta `schemaError.value = null`; catch'te `schemaError.value = e?.message || 'Şema
  yüklenemedi. Bağlantı ayarlarını kontrol edin.'` (console.error korunur).
- Template fallback bloğu ikiye ayrılır (loading bloğundan sonra):
  - **Hata** (`v-else-if="schemaError"`): kırmızı-tonlu kart, uyarı ikonu, `schemaError` mesajı,
    "Tekrar dene" butonu → `loadSchema(true)` (+ ayarlar ipucu metni).
  - **Boş** (`v-else-if="!schema || tablolar===0"`): nötr, "Bağlantı kuruldu ancak tablo bulunamadı /
    henüz şema içe aktarılmadı" + "Şemayı içe aktar / Yenile" butonu → `loadSchema(true)`.
- Üstteki "Önbelleği Yenile" butonu korunur.

Runtime davranış değişimi yok (hata artık görünür + retry); başarı akışı aynı; yeni bağımlılık yok.

## 3. Verify (frontend — pytest/CI yok)
`cd frontend && npm run build` → **0 hata, exit 0**. Görsel akıl-yürütme: loadSchema reddi→hata kartı+retry;
0 tablo & hata yok→boş kart+import; başarı→tablo listesi.

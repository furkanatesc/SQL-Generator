**Faz:** Phase 8 — Observability & Debuggability
**Tarih:** 2026-07-01
**Önceki sprint:** 27.0 End-to-End Trace Contract (çatı + EXECUTION/SECURITY referans span'leri)

---

## §0. Amaç ve tek cümlelik özet

27.0'ın kurduğu `EndToEndTrace` çatısına **kalan 5 pipeline stage'i** için —
INTENT, RETRIEVAL, PROMPT, GENERATION, VALIDATION — saf, deterministik,
secret-free, I/O-free, **duck-typed** span builder'ları ve bunların typed
`*SpanDetail` dataclass'larını eklemek. 27.0 kalıbının birebir devamı:
`app.trace.*` dışına import yok, driver-isolation korunur, tüm zamanlamalar
caller-supplied.

Bu sprint sonunda 7 stage'in tamamının span builder'ı hazır olur; **canlı
pipeline'a örme (live wiring) bu sprintin KAPSAMI DIŞIDIR** (bkz. §6).

## §2. Bağlayıcı invariant'lar (27.0'dan devralınan, değişmez)

1. **Saf, deterministik, secret-free, I/O-free.** Network/DB/clock/random/file
   I/O yok. `duration_ms` **caller-supplied** (GENERATION istisnası: builder,
   verilmezse `.response.latency_ms`'ten türetebilir — bu bir I/O değil, girdi
   üzerinden okuma).
2. **Ham veri asla taşınmaz.** Ham NL query / `normalized_query` / ham SQL / ham
   prompt / validation `message` metni **hiçbir detail'e girmez.** Yalnız:
   sha256'lar (64-hex), sayılar, enum/kod/id adları, ve gerekiyorsa
   `app/trace/redaction.py` ile sanitize edilmiş metin.
3. Tüm public kayıtlar `@dataclass(frozen=True)`.
4. **Driver-isolation korunur.** `import app.trace.end_to_end_trace_builders`
   yalnız stdlib + `app.trace.end_to_end_trace` + `app.trace.redaction` çeker;
   `app.evaluation`, `app.query_understanding`, `app.retrieval`,
   `app.sql_generation` veya DB driver'larını **yüklemez.** Builder'lar
   **duck-typed** (26.11/27.0 projektör kalıbı: `Any` alıp `getattr` ile okur).
5. **Granülerlik:** bir EndToEndTrace = bir NL→SQL isteğinin tüm yaşam döngüsü.
   Stage başına tek span.
6. Yerleşim yalnız `backend/app/trace/`; testler `backend/tests/trace/`.
7. Commit mesajları: `feat(observability): 27.1 ...`. Claude co-author trailer
   YOK.

## §4. Span detail'leri, kaynak alanları ve status semantiği

Kaynak alan adları koddan teyit edildi. Builder'lar bu alanları `getattr` ile
okur; kaynak tipini sert import etmez.

### 4.1 INTENT — `build_intent_span(result, *, duration_ms=None)`
Kaynak: `IntentExtractionResult` → `.intent` (`QueryIntent`), `.extraction_version`.

```python
@dataclass(frozen=True)
class IntentSpanDetail(TraceSpanDetail):
    intent_type: str                          # list/aggregate/comparison/ranking/count/unknown
    flags: Tuple[str, ...] = ()               # aktif olan boolean adları, ör. ("has_filter","requires_join")
    ambiguity_detected: bool = False
    signal_names: Tuple[str, ...] = ()        # yalnız IntentSignal.name — value/reason DIŞLANIR
    extraction_version: Optional[str] = None
```
- `flags`: `has_filter/has_aggregation/has_grouping/has_ordering/has_limit/`
  `requires_join/has_time_range` içinden `True` olanların adları (deterministik,
  sabit sıra).
- `normalized_query`, signal `value`/`reason` **taşınmaz** (secret-free).
- **Status:** `ambiguity_detected` veya `intent_type=="unknown"` → **WARNING**;
  yoksa **OK**; girdi `None` → **SKIPPED**.

### 4.2 RETRIEVAL — `build_retrieval_span(result, *, duration_ms=None)`
Kaynak: `TopKRetrievalResult` (`k_requested`, `k_returned`, `candidates`,
`retrieval_version`); her `RetrievalCandidate` tamamen secret-free (ama `.text`
NL taşır → dışlanır).

```python
@dataclass(frozen=True)
class RetrievalCandidateRef:
    object_id: str
    object_type: str                          # table/column/relationship
    score: float
    rank: int
    schema_hash: Optional[str] = None

@dataclass(frozen=True)
class RetrievalSpanDetail(TraceSpanDetail):
    k_requested: Optional[int] = None
    k_returned: Optional[int] = None
    candidates: Tuple[RetrievalCandidateRef, ...] = ()   # candidate.text DIŞLANIR
    retrieval_version: Optional[str] = None
```
- **Status:** `k_returned == 0` (veya boş candidates) → **WARNING** (hiçbir
  context bulunamadı); >0 → **OK**; `None` → **SKIPPED**.

### 4.3 PROMPT — `build_prompt_span(gen_input, *, duration_ms=None)`
Kaynak: `SQLGenerationInputResult` (zaten `prompt_sha256` taşıyor — en temiz
sınır objesi).

```python
@dataclass(frozen=True)
class PromptSpanDetail(TraceSpanDetail):
    prompt_sha256: Optional[str] = None       # ham prompt DEĞİL
    prompt_char_count: Optional[int] = None
    intent_type: Optional[str] = None
    target_dialect: Optional[str] = None
    source_section_types: Tuple[str, ...] = ()
    source_item_ids: Tuple[str, ...] = ()
    input_version: Optional[str] = None
```
- `rendered_prompt`, `raw_query`, `normalized_query` **taşınmaz.**
- **Status:** **OK**; `None` → **SKIPPED**. (Prompt render başarısızlığı canlı
  yolda ayrı hata olarak yüzeye çıkar; bu builder başarı objesini normalize eder.)

### 4.4 GENERATION — `build_generation_span(provider_result, *, duration_ms=None)`
Kaynak: `SQLGenerationProviderResult.response` (`SQLGenerationProviderResponse`):
`provider_id/model_id/finish_reason/prompt_sha256/output_sha256/latency_ms/`
`token_usage`.

```python
@dataclass(frozen=True)
class GenerationSpanDetail(TraceSpanDetail):
    provider_id: Optional[str] = None
    model_id: Optional[str] = None
    finish_reason: Optional[str] = None
    prompt_sha256: Optional[str] = None
    output_sha256: Optional[str] = None       # ham SQL DEĞİL
    prompt_tokens: Optional[int] = None
    completion_tokens: Optional[int] = None
    total_tokens: Optional[int] = None
```
- `raw_text`/`generated_sql_text` **taşınmaz** (yalnız `output_sha256`).
- `duration_ms` verilmezse builder `.response.latency_ms`'ten türetir.
- **Status:** boş output / `finish_reason` bir hata/`error` kodu → **ERROR**;
  `finish_reason` truncation göstergesi (`"length"`) → **WARNING**; normal
  tamamlanma → **OK**; `None` → **SKIPPED**. (Kesin `finish_reason` eşleşme
  kümeleri implementasyonda sabitlenecek; bilinmeyen kod güvenli varsayılan
  **OK**.)

### 4.5 VALIDATION — `build_validation_span(issues, *, valid, sql_sha256=None, duration_ms=None)`
Hazır tek dataclass yok (§1). **Genel issue dizisi + `valid` bayrağı** girdisi
(kullanıcı onaylı) — legacy `validation_errors` dict'lerine DE, modüler contract
objelerine DE uyarlanabilir; SECURITY builder'ının "checks dizisi → SKIPPED/OK/
WARNING/ERROR" kalıbına paralel.

```python
@dataclass(frozen=True)
class ValidationIssue:
    category: str                             # ör. type/stage adı: syntax_error, missing_column, unsafe_sql...
    stage: Optional[str] = None
    severity: Optional[str] = None
    reason_code: Optional[str] = None

@dataclass(frozen=True)
class ValidationSpanDetail(TraceSpanDetail):
    valid: bool = True
    sql_sha256: Optional[str] = None
    issues: Tuple[ValidationIssue, ...] = ()   # issue MESAJI DIŞLANIR
```
- Her issue duck-typed okunur: `category = getattr(e,"category",None) or
  getattr(e,"type",None)`; `stage`, `severity`, `reason_code = getattr(...) or
  getattr(e,"type",None)`. **`message` alanı asla okunmaz** (SQL/kolon adı
  sızabilir).
- **Status:** `valid is False` → **ERROR**; valid ama issue var → **WARNING**;
  temiz → **OK**; `issues is None` (stage koşmadı) → **SKIPPED**.

## §5. Builder ortak kalıbı

- 27.0 kalıbı: `getattr` ile oku; eksik/`None` alan → güvenli default; bariz
  sözleşme ihlali (ör. tanınmayan zorunlu enum) → `EndToEndTraceError`.
- `None` girdi → o stage için `TraceSpanStatus.SKIPPED` span'i (SECURITY'nin boş
  dizi → SKIPPED kalıbına paralel).
- Enum-or-str normalizasyonu için mevcut `_status_str` (getattr `.value`)
  yeniden kullanılır.
- İmzalar:
  ```python
  build_intent_span(result, *, duration_ms=None) -> TraceSpan
  build_retrieval_span(result, *, duration_ms=None) -> TraceSpan
  build_prompt_span(gen_input, *, duration_ms=None) -> TraceSpan
  build_generation_span(provider_result, *, duration_ms=None) -> TraceSpan
  build_validation_span(issues, *, valid, sql_sha256=None, duration_ms=None) -> TraceSpan
  ```

## §7. Test stratejisi (TDD)

Her builder için:
1. **Happy path** — kaynak objeden doğru detail üretimi.
2. **Her status geçişi** — OK / WARNING / ERROR / SKIPPED (None girdi dahil).
3. **Secret-free assertion** — üretilen span'de ham query/sql/prompt/normalized_
   query/issue-message **bulunmadığını** ve yalnız hash/sayı/kod/id olduğunu
   kanıtla (`to_payload()` üzerinde string-taraması dahil).
4. **`to_payload` round-trip** — her yeni detail JSON-safe serialize olur (nested
   `RetrievalCandidateRef`/`ValidationIssue` dahil).

Ek testler:
- **Driver-isolation:** `end_to_end_trace_builders` import edildiğinde
  `sys.modules`'a `app.query_understanding`/`app.retrieval`/`app.sql_generation`/
  DB driver'ları girmez (27.0 T3 kalıbı).
- **7-span assembly:** 7 stage span'i tek `build_end_to_end_trace`'e birleşir;
  terminal derivation ve `to_payload` bütünsel doğrulanır.

Baseline: 27.0 sonrası full suite **1998 passed / 9 skipped**; 27.1 sonrası 0
regresyon + yeni testler yeşil.

# Sprint 31.4 — Execution Result Viewer (Design Spec)

> Frontend sprint (Vue 3). No pytest/CI — verify via `npm run build`.
> Phase 12 beşinci frontend sprint'i. Kullanıcı direktifi: soru sorma, kapsam kararını kendin ver.

## 1. Problem / Brainstorm (karar — dürüst kapsam)
"Execution Result Viewer" = üretilen SQL'in çalıştırılıp **sonuç satır/sütunlarının** gösterildiği görünüm.

**Blokaj (araştırma ile doğrulandı, sessiz düşürme YOK):** Backend'de **canlı DB execution HİÇ yapılmadı**
(TECH-DEBT §30 — Phase 11 devri; `query_runs` inert, sonuç request'te *sağlanır*, gerçek SELECT
çalıştırılmaz; canlı execution = secret-resolution + read-only bağlantı, **güvenlik-hassas/kullanıcı-onaylı**).
Frontend tarafı: `api.ts::Job` yalnız `result_sql` taşır; `ChatView`/`History`/hiçbir yerde columns/rows
YOK; `uploadFile` satır döndürmez. Yani **frontend'e akan gerçek execution sonucu yoktur.**

**Karar:** Backend'e canlı execution EKLEMEK kapsam dışı (kullanıcı-onaylı/güvenlik-hassas). Yalın,
spekülatif-olmayan iş: **sunum tarafını inşa et** — 30.4 `QueryRunResult` kontratına (`columns`/`rows`/
`truncated`/`duration_ms`) birebir uyan, yeniden-kullanılabilir salt-okunur bir `ResultTable.vue`
bileşeni + `ChatView`'e opsiyonel `result` alanıyla gerçek bir entegrasyon noktası. Sonuç verisi henüz
akmadığı için **fake/dead tablo GÖSTERİLMEZ**; bunun yerine SQL bloğunun altında **dürüst bir bilgi
notu**: "Bu sürümde sorgu yalnız üretilir, çalıştırılmaz (canlı execution bağlı değil)." Bu, kullanıcının
beklentisini doğru kurar ve execution sprint'i (§30) bağlandığında `msg.result` doldurularak tablo
otomatik görünür. Böylece roadmap sprint'i dürüstçe ilerler; ne fake veri ne sessiz atlama.

## 2. Design
- **`api.ts`:** `export interface QueryResult { columns: string[]; rows: unknown[][]; truncated?: boolean; duration_ms?: number | null }` (30.4 `QueryRunResult` birebir).
- **Yeni `frontend/src/components/ResultTable.vue`:** prop `result: QueryResult`. Kaydırılabilir
  `<table>` (sticky header = `columns`, gövde = `rows`; hücre `null`→`NULL` italik zinc); üst barda
  satır sayısı + `duration_ms` (varsa `... ms`) + `truncated` ise "kesildi" rozeti; `rows` boşsa
  "Sonuç boş" durumu. Erişilebilir tablo semantiği (`<th scope="col">`), yatay `overflow-x-auto`
  (sayfa gövdesi yatay kaymaz). Salt-okunur, motion yok.
- **`ChatView.vue`:** `ChatMessage`'a `result?: QueryResult` (opsiyonel) eklenir; `import ResultTable`.
  SQL kartının altına "Sonuç" bölümü: `v-if="msg.result"` → `<ResultTable :result="msg.result" />`;
  aksi hâlde (`msg.sql` varken) dürüst tek-satır bilgi notu (§30 gerçeğini yansıtır). Mevcut
  SQL/copy/açıklama(31.3)/log akışı DEĞİŞMEZ.

Runtime davranış değişimi yok (yeni salt-okunur sunum + henüz doldurulmayan opsiyonel alan); backend değişmez.

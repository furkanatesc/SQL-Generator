# Sprint 28.4 — Relationship Confidence Scoring · Tasarım (Design Spec)

**Phase:** 9 — Large Schema Production Scale (28.3'ün ardılı)
**Tarih:** 2026-08-07
**Tür:** Üretim seçim modeli iyileştirmesi (confidence-weighted neighbor benefit) — config-driven
**Önceki:** 28.3 Table Selection Cost Model (PR #153) + 28.3.1 Tech-Debt Cleanup (PR #154) · **Sonraki:** 28.5 Missing Foreign Key Inference v2

---

## 1. Amaç ve bağlam

28.3'ün `TableSelectionCostModel`'inde komşu (neighbor) expansion **düz**: `explicit_neighbor=20`,
`implicit_neighbor=10`; IMPLICIT_FUZZY hiç expand edilmiyor. Bu, `RelationshipSchema.confidence`
bilgisini (implicit ilişkiler için detect_implicit_relationships tarafından atanan 0.60-0.90;
explicit FK'ler için `None`) HİÇ kullanmıyor — güven iki tür-ağırlığında yarı-kodlu.

TECH-DEBT §12.13'te bu iş bilinçli olarak 28.4'e ayrılmıştı: "ilişki-güven-ağırlıklı komşu
benefit'i yok — 28.3 düz 20/10'u config modeline taşıdı, güven-ağırlıklandırmayı eklemedi."

28.4 komşu benefit'ini **confidence tek güven sinyali** olacak şekilde çarpımsal yapar:
`neighbor_benefit = neighbor_base × effective_confidence`. Bu, tür-bazlı çift-sayımı ortadan
kaldırır (confidence trust'i tek başına kodlar) ve implicit/fuzzy ilişkilerin gerçek güven
skorunu seçime yansıtır.

### Merkezi tasarım kararı — çarpımsal, tek base, config-driven
Cost model'in iki komşu ağırlığı (`explicit_neighbor`/`implicit_neighbor`) tek bir
`neighbor_base`'e indirgenir; komşu benefit'i `neighbor_base × effective_confidence` olur.
`effective_confidence = rel.confidence if rel.confidence is not None else 1.0` (explicit/custom
= kesin = 1.0). Fuzzy komşular yeni `include_fuzzy_neighbors` config bayrağıyla opt-in
(varsayılan KAPALI → bugünkü dışlama korunur). Selector saf-leaf kalır; `probe`/`node_budget`/
`cost_budget` mantığı korunur; confidence yalnız **benefit**'i etkiler.

## 3. Cost model değişikliği — `app/schema/table_selection_cost.py`

`TableSelectionCostModel` (frozen, `extra="forbid"`):
- **KALDIRILIR:** `explicit_neighbor: float = 20.0`, `implicit_neighbor: float = 10.0`.
- **EKLENİR:**
  ```python
  neighbor_base: float = 20.0            # confidence ile carpilir
  include_fuzzy_neighbors: bool = False  # fuzzy komsu opt-in
  ```
- `from_config` `_KNOWN_FIELDS` seti güncellenir: `explicit_neighbor`/`implicit_neighbor`
  çıkar, `neighbor_base` girer; `include_fuzzy_neighbors` bool olarak kabul edilir (mevcut
  `from_config` yalnız `_is_number` kabul ediyor → bool alanı için parse'ı genişlet: bilinen
  bool alanı `isinstance(v, bool)` ile alınır, sayılar `_is_number` ile). Eski config'lerdeki
  `explicit_neighbor`/`implicit_neighbor` anahtarları bilinen-alan filtresiyle sessizce düşer
  (toleranslı; hata yok).
- Yeni saf yardımcı (opsiyonel, netlik için):
  ```python
  def neighbor_benefit(rel_confidence: float | None, model: TableSelectionCostModel) -> float:
      conf = rel_confidence if rel_confidence is not None else 1.0
      return model.neighbor_base * conf
  ```
- `table_cost`/`fk_counts`/`cost_budget`/benefit relevance ağırlıkları (exact_table vb.)
  DEĞİŞMEZ.

## 4. Selector değişikliği — `select_schema_context` neighbor expansion

Mevcut blok (~satır 97-111): her komşu ilişki için tür'e göre `add_score(neighbor,
cost_model.explicit_neighbor|implicit_neighbor, reason)`. Yeni:
- EXPLICIT / CUSTOM / IMPLICIT komşu → `benefit = neighbor_base × effective_confidence`
  (`effective_confidence = rel.confidence if not None else 1.0`); `add_score(neighbor, benefit,
  reason)`.
- IMPLICIT_FUZZY komşu → yalnız `cost_model.include_fuzzy_neighbors` True ise dahil
  (`benefit = neighbor_base × rel.confidence`); default False → **continue** (bugünkü davranış).
- Reason string'i confidence'i yansıtır (şeffaflık), ör. `f"{rel_type}_neighbor_of_{t_name}
  (conf={effective_confidence})"` — mevcut reason formatına uyumlu, tek kaynak.
- `probe.incr("related_expansion")` sayacı korunur. Seçim algoritması (exact-focus garanti,
  benefit-density greedy under cost_budget, max_tables cap), `probe`, `node_budget`,
  `cost_budget`, join-path discovery, fallback — HEPSİ DEĞİŞMEZ.
- Confidence yalnız komşu **benefit**'ini etkiler; `table_cost` (cost) ve `find_join_paths`
  (join-path) DOKUNULMAZ.

### Determinizm & purity
Selector saf stdlib+pydantic; `effective_confidence` şemadan gelir (seed-free deterministik).
Model injected (28.3 deseni).

## 5. Kalibrasyon

`neighbor_base = 20.0` konservatif seçim: explicit komşu (conf 1.0) → 20 = eski
`explicit_neighbor` (explicit-ağırlıklı şemalarda değişim minimal); implicit komşu artık
`20 × [0.60..0.90] = 12..18` (eski düz 10'dan mütevazı yükseliş, ama explicit'in 20'sinin
altında → tür sıralaması confidence ile doğru korunur). Golden şemada doğrulanır; required
tablolar düşmez / forbidden çekilmezse değer korunur, aksi halde ayarlanır (gerekçeyle).

## 6. Davranış-değişimi yönetimi

- **Golden eval** (`test_context_selection_golden_eval.py`, constraint-based): komşu benefit
  değişimi required⊆selected ve forbidden∩selected=∅ kısıtlarını bozmazsa YEŞİL kalır. Değişen
  case incelenir, hâlâ doğruysa gerekçeyle curate edilir; required/forbidden girdisi silinerek
  yeşile zorlanmaz.
- **Benchmark:** `context_selection` hedefi yalnız sentetik şemada explicit-olmayan (implicit/
  fuzzy) komşular varsa etkilenir. **Önce ölç:** `run_benchmark` context_selection metrikleri
  (focus/selected_tables_total) değişiyorsa `BENCHMARK_SCHEMA_VERSION = "large_schema_benchmark_v5"`
  + gated baseline (100/500/1000) yeniden üretilir + version-literal testleri (test_bench_contract/
  test_bench_metrics) v5; DEĞİŞMİYORSA v4 korunur (28.3'te olduğu gibi join_paths/implicit_fk
  zaten etkilenmez). 28.3 Task 5 deseni.
- **Config:** `from_config` toleranslı; eski `explicit_neighbor`/`implicit_neighbor` config
  anahtarları sessizce düşer. Pipeline enjeksiyonu değişmez.

## 8. Bilinçli kapsam DIŞI (TECH-DEBT'te işaretlenir / AÇIK kalır)

- **Explicit FK'lere confidence < 1.0** — declared FK'ler kesin (None→1.0); güven modellemesi
  kapsam dışı.
- **Confidence'i join-path scoring'e / cost'a taşıma** — 28.4 yalnız komşu **benefit**; join-path
  ve cost dokunulmaz.
- **Token-tabanlı maliyet** (§12.14), **gerçek knapsack** (§12.15), **hub-penalty path scoring**
  (§12.9), **GraphPruner** (§12.5/10), **frontend maxNodesLimit** (§2, Phase 12) — açık kalır.
- **Fuzzy expansion'ı default açma** — bilinçli olarak opt-in bırakıldı (fuzzy nitelik-güvensizliği).

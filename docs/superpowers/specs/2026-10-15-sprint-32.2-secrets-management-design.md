# Sprint 32.2 — Secrets Management (Design)

Phase 13 · Branch `feat/32.2-secrets-management` · Önceki: 32.0 (prod compose), 32.1 (env sözleşmesi).

## 1. Problem & karar

32.1 sözleşmesinde `secret=True` olan iki değişken (`NL2SQL_API_KEY`, `NVIDIA_API_KEY`) yalnız düz
env değişkeni olarak okunuyor ve okuma 9 noktaya dağılmış (`auth.py`, `startup_validation.py`,
`llm_client.py`, `main.py` ×4, `sql_pipeline.py` ×2). Prod compose key'i container env'ine koyuyor
(`docker inspect`, `/proc/*/environ`, alt süreçler ve crash dump'larla görünür). TECH-DEBT §36.3/§37.1.

**Karar (kapsam):** 32.2 = **tek secret resolver** (`app/secret_resolver.py`) + **dosya-tabanlı secret
(`<NAME>_FILE`, Docker secrets konvansiyonu)** + **prod compose'ta API key'in Docker secret'a
taşınması** + **secret kaynak teşhisi için startup uyarıları**. DB > env/dosya önceliği DEĞİŞMEZ
(32.0 kararı; operatör `POST /api/configs/api_key` ile değiştirir) ama gölgelenme artık görünür.

Seçilmeyen:
- (a) Harici secret store (Vault/AWS SM) — bağımlılık + çalışan altyapı yok; resolver arayüzü
  sonradan provider eklemeye uygun bırakıldı (§36.3 → TECH-DEBT §38).
- (b) DB > env önceliğini tersine çevirmek — prod'da `POST /api/configs/api_key` ile yapılmış
  rotasyonu sessizce geri alır; davranış değişikliği. Yerine `API_KEY_ENV_SHADOWED` uyarısı.
- (c) `NVIDIA_API_KEY`'i de compose secret'ı yapmak — compose `secrets.file` opsiyonel olamaz
  (dosya yoksa stack açılmaz), key opsiyonel. Resolver `NVIDIA_API_KEY_FILE`'ı destekler; compose
  env-opsiyonel kalır, runbook override örneği verir.
- (d) Dosyayı cache'lemek — her çağrıda oku (≤64 KiB, tek küçük dosya); rotasyon restart'sız etkili.

## 2. Design

### 2.1 `app/secret_resolver.py`
- `SECRET_FILE_VARS = {"NL2SQL_API_KEY": "NL2SQL_API_KEY_FILE", "NVIDIA_API_KEY": "NVIDIA_API_KEY_FILE"}`
  (literal — 32.1 drift guard'ı literal arar). Anahtar kümesi = sözleşmedeki `secret=True` kümesi (test).
- `resolve_secret_detail(name, environ=None) -> SecretResolution(name, source, value, error, conflict)`:
  1. `<NAME>_FILE` doluysa dosyayı oku: `strip()`; okunamaz → `error="unreadable"`, boş →
     `"empty"`, >64 KiB → `"too_large"`; hata durumunda **env'e düşme yok** (operatör açıkça dosya
     seçti; sessiz bayat-değer kullanımı engellenir). `source="file"`.
  2. Yoksa `<NAME>` env (boş string = yok). `source="env"`.
  3. Yoksa `source="none"`.
  `conflict = file var ve env var ikisi de dolu` (dosya kazanır). `value` `repr=False`. Bilinmeyen
  ad → `KeyError` (yalnız sözleşme secret'ları).
- `resolve_secret(name, environ=None) -> str | None`, `known_secret_values(environ=None) -> set[str]`.

### 2.2 Okuma noktaları → resolver
`auth.verify_api_key`, `startup_validation`, `llm_client.get_nvidia_api_key`, `main.py` 4 NVIDIA
kontrolü, `sql_pipeline` redaction (`known_secret_values()` — dosyadan gelen değer env'de olmadığı için
eski KEY/SECRET/PASSWORD/TOKEN env taraması onu yakalamazdı; tarama korunur).

### 2.3 Startup uyarıları (`validate_runtime_config`)
| Kod | Severity | Koşul |
|---|---|---|
| `API_KEY_NOT_CONFIGURED` | critical | DB key yok ve resolver key yok (dosya dahil) |
| `SECRET_FILE_UNREADABLE` | critical | `<NAME>_FILE` set ama okunamaz/boş/çok büyük (mesaj değişken adını verir, yol/değer değil) |
| `SECRET_SOURCE_CONFLICT` | warning | hem `<NAME>` hem `<NAME>_FILE` set (dosya kazanır) |
| `API_KEY_ENV_SHADOWED` | warning | DB key ve env/dosya key ikisi de var ve farklı (DB kazanır; env/dosya rotasyonu etkisiz) |

`API_KEY_INSECURE_DEFAULT` etkin key hesabı resolver ile.

### 2.4 Sözleşme (`config_contract.py`)
Yeni *direct* girişler: `NL2SQL_API_KEY_FILE`, `NVIDIA_API_KEY_FILE` (secret=False — yol, değer
değil; required_in_production=False). `CONTRACT_VERSION` `v1` kalır (eklemeli). Prod-zorunlu
sözleşme testi: zorunlu secret'lar compose'ta `<NAME>_FILE: /run/secrets/...` + bildirilmiş secret
ile de karşılanabilir.

### 2.5 Prod compose
- Backend env'inden `NL2SQL_API_KEY` kalkar; `NL2SQL_API_KEY_FILE: /run/secrets/nl2sql_api_key` sabit;
  `secrets: [nl2sql_api_key]`; üst-seviye `secrets.nl2sql_api_key.file:
  ${SQLGEN_API_KEY_SECRET_FILE:?...}` (compose-only değişken, fail-fast korunur).
- `.env.prod.example`: `SQLGEN_API_KEY_SECRET_FILE=./secrets/nl2sql_api_key`; `.gitignore`: `secrets/`.
- Dosya izinleri: container non-root `app` kullanıcısı → dosya 0444/0644 olmalı (runbook).
- CI `prod-compose-smoke`: secret dosyasını yazar, ek doğrulama: key container env'inde YOK.

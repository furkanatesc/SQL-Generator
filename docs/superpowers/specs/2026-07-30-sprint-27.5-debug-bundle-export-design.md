# Sprint 27.5 — Debug Bundle Export (design)

**Tarih:** 2026-07-30
**Faz:** 8 (Observability & Debuggability)
**Öncül:** Sprint 27.4 (Query Replay System, PR #141 merged; doküman senkronu PR #142).
Gözlemlenebilirlik katmanı artık her koşunun `end_to_end` trace'ini yazıyor (27.1w),
hataları tek registry'den kodluyor (27.2/27.2.1), kullanıcı feedback'ini topluyor (27.3)
ve geçmiş bir job'ı deterministik olarak yeniden koşup baseline'la karşılaştırabiliyor
(27.4). Bu sprint bir sonraki soruyu cevaplar: **"bir job hakkındaki her şeyi, güvenle
paylaşılabilir tek bir pakette nasıl dışa aktarırım?"**

## 1. Amaç

Tek bir `job`'ın tüm debug bağlamını — `end_to_end` trace'i, 27.4 replay sonucu, seçilen
şema özeti ve ortam/sürüm metadata'sını — **tek bir JSON envelope**'da toplayıp
**bir hata raporuna iliştirilebilecek** taşınabilir bir artefakt üretmek.

Birincil tüketici: **hata raporu eki** (issue/bug report). Bu yüzden iki tasarım kısıtı
her şeyin önündedir:
- **Paylaşılabilirlik:** çıktı taşınabilir, kendi kendine yeterli tek bir belge.
- **Güvenlik:** hiçbir secret / credential / bağlantı bilgisi sızmaz; yeni yüzeyler
  (şema + metadata) **allow-list** ile korunur (varsayılan: dışarıda).

Export **yan etkisizdir**: hiçbir şey yazılmaz, hiçbir trace emit edilmez, LLM'e gidilmez.
Replay 27.4 gibi **inline ve deterministik** koşar.

## 2. Kapsam

### Kapsam içi
1. Saf yaprak paket `backend/app/debug_bundle/`: frozen `DebugBundle` + alt-record'lar,
   allow-list projektörleri, saf `compose_bundle()`, `to_payload()` (JSON-safe, deterministik).
2. Kirli adaptör `backend/app/bundle_service.py`: job + en yeni `end_to_end` trace + (SQL
   taşıyan) debug trace okur, `end_to_end` trace'i **mevcut redaksiyon geçişleriyle** temizler
   (debug trace zaten `serialize_trace_for_debug`'tan redakte gelir), 27.4 `replay_job`'ını
   inline koşar, saf `compose_bundle`'ı çağırır.
3. Debug endpoint `GET /api/debug/jobs/{job_id}/bundle` (API key + `debug_endpoints_enabled`
   ile gated), 200 envelope `{status, bundle}`.
4. `schemas.py`'ye `BundleEnvelopeResponse` + `BundleDetailResponse`; `main.py` router mount.
5. **Hedefli iyileştirme:** `redact_sensitive_dict`'i `app/trace/debug_api.py`'den
   `app/trace/redaction.py`'ye taşı; hem `/api/debug/traces` hem bundle adaptörü tek saf
   kaynaktan kullansın (davranış korunur, `debug_api.py` re-export eder).
6. Contract snapshot yenileme (`openapi_snapshot.json` yeni route ile) + `test_api_surface.py`
   route seti — **bilinçli**, blind blessing değil.
7. Yaşayan doküman kapanışı (PLANNED-SPRINTS, SPRINT-PR-LOG, gerekiyorsa TECH-DEBT + hafıza).

## 3. Tasarım

### 3.1 Saf yaprak paket — `backend/app/debug_bundle/`

İzinli import yüzeyi: **stdlib + `app.replay.contract` / `app.replay.verdicts`**
(frozen tipler ve `REPLAY_CONTRACT_VERSION` — `app.replay` 27.4'te saf leaf paket olarak
kanıtlandı). Yasak: `pydantic`, `fastapi`, `app.database`, `app.trace.*`, herhangi bir
DB driver. Purity guard testi ile **taze bir alt süreçte** kilitlenir (27.4 dersi:
aynı süreçte `sys.modules` cache'i sızıntıyı maskeler).

> **`app.trace.redaction` neden import EDİLMİYOR** (27.4, Task 3 dersinin doğrudan sonucu):
> `redaction.py` modülünün *kendisi* neredeyse saftır (`from app.errors import ErrorCode`),
> ama ona giden **yol** saf değildir — Python bir alt modülü import ederken paketin
> `__init__`'ini de çalıştırır ve `app/trace/__init__.py` tüm paketi eager import eder
> (`sqlite_store`, `debug_api`…). Bu yüzden **metin redaksiyonu saf katmanda yapılamaz**;
> kirli adaptörde (§3.2) yapılır ve saf `compose_bundle` **zaten-redakte** bir trace
> payload'ı alır.

Modüller:
- `contract.py` — frozen record'lar + `to_payload()`:
  - `DebugBundle(version, job_id, job, trace, sql, replay, schema, meta)`
  - `BundleJobInfo` — allow-list + varlık bayrakları (aşağıda §3.4)
  - `BundleSqlInfo(generated_sql, last_generated_sql, sql_valid, attempts, sql_validation_errors)`
    — **zaten redakte** debug-trace payload'ından allow-list ile alınır (§3.1a, §3.5)
  - `BundleSchemaInfo(selected_tables, schema_hash, table_count)`
  - `BundleMeta(bundle_contract_version, replay_contract_version, trace_contract_version, dialect)`
  - `replay` alanı 27.4 `ReplayResult.to_payload()` çıktısını (plain dict) taşır.
  - **Sürüm kaynakları (purity):** `bundle_contract_version` paketin kendi sabiti;
    `replay_contract_version` `app.replay.verdicts.REPLAY_CONTRACT_VERSION`'dan (izinli);
    `trace_contract_version` ise **import edilmez** — trace payload'ının `version`
    alanından okunur (`END_TO_END_TRACE_CONTRACT_VERSION` sabitini import etmek
    `app/trace/__init__`'i tetikler, §3.1 not). Trace yoksa `None`.
- `projectors.py` — saf allow-list projeksiyonları:
  - `project_job(job_dict) -> BundleJobInfo` — yalnız whitelisted alanlar + `has_*` bayrakları.
    **Ham `natural_query` / `result_sql` metni GİRMEZ** (kullanıcı kararı: seçenek 3 —
    SQL/prompt metni yalnız trace projeksiyonunda, redakte hâliyle görünür).
  - `project_schema(trace_payload, replay_payload) -> Optional[BundleSchemaInfo]` — trace'in
    `retrieval` span'inden `selected_tables`, `security` span'inden `schema_hash`; trace yoksa
    replay'in gözlediği tablolardan (`retrieval.observed_tables`) türet; hiçbiri yoksa `None`.
  - `project_sql(debug_trace_payload) -> Optional[BundleSqlInfo]` — **zaten redakte** debug-trace
    payload'ından (§3.1a) yalnız whitelisted alanları alır: `generated_sql`, `last_generated_sql`,
    `sql_valid`, `attempts`, `sql_validation_errors`. Debug trace yoksa `None`. **Ham job metni
    (`natural_query`/`result_sql`) buraya GİRMEZ** — kaynak yalnız redakte debug-trace'tir.
  - `project_meta(...) -> BundleMeta` — yalnız whitelisted sürüm/dialect alanları; env
    dump / connection / api key ASLA.
- `compose.py` — `compose_bundle(*, job, redacted_trace_payload, redacted_debug_trace_payload, replay_payload, dialect) -> DebugBundle`
  saf birleştirici; determinizm sözleşmesi: aynı girdi → aynı `to_payload()`.

**§3.1a — İki trace kavramı (kritik ayrım).** Kod tabanında job'a bağlı İKİ trace türü var:
1. **`end_to_end` trace** (spec'in `trace` bölümü + replay baseline'ı): tasarımca **secret-free**,
   ham SQL/prompt taşımaz — yalnız `prompt_sha256`/`output_sha256` + char-count + yapısal span'ler.
2. **Debug trace** (`/api/debug/traces`'in döndürdüğü, `trace_debugging.md` sözleşmesi):
   `generated_sql`/`last_generated_sql`/`sql_valid`/`attempts`/`sql_validation_errors` taşır ve
   `serialize_trace_for_debug` ile **redakte edilir**.
Bu yüzden `trace` bölümü (1)'den, `sql` bölümü (2)'den beslenir. Reprodüksiyon değeri (redakte SQL)
yalnız `sql` bölümünde bulunur.

### 3.2 Kirli adaptör — `backend/app/bundle_service.py`

27.4 `replay_service.py` desenini izler. DB, trace store ve pipeline'a dokunur.

```
build_bundle(job_id, *, trace_store, pipeline) -> dict   # to_payload çıktısı
```
Akış:
1. `job = get_job(job_id)`; `None` → `BundleJobNotFound` (kaynak hatası, replay değil).
2. En yeni `end_to_end` trace payload'ı (27.4 `_latest_baseline_payload` ile aynı sorgu;
   ortak yardımcıya çıkarılabilir). Store hatası **YUTULMAZ** → yukarı çıkar (§3.6).
3. `end_to_end` trace payload'ını **redakte et**: `serialize_trace_for_debug`'ın iki geçişini
   (`redact_sensitive_dict` → `redact_sensitive`) yeniden kullan. (Redaksiyon kirli
   tarafta; §3.1 gerekçesi.) Trace yoksa `redacted_trace_payload = None`.
4. **Debug trace payload'ı** (SQL taşıyan, §3.1a-2): `DebugTraceAdapter(trace_store)` ile
   job'ın **`end_to_end` OLMAYAN** en yeni trace'ini çek — adapter zaten
   `serialize_trace_for_debug`'tan geçirir, yani `redacted_debug_trace_payload` **redakte**
   gelir. Yoksa `None`.
5. `replay_payload = replay_job(job_id, pipeline, trace_store).to_payload()` — inline,
   yan-etkisiz, LLM yok. `baseline_unavailable` / input-yok verdict'leri olduğu gibi girer.
6. `compose_bundle(job=job, redacted_trace_payload=..., redacted_debug_trace_payload=...,
   replay_payload=..., dialect=...)`.
7. `.to_payload()` döndür.

### 3.3 Router — `backend/app/api/debug_bundle_api.py`

`debug_replay.py` ile birebir simetrik: kendi `APIRouter`'ı (`prefix="/api/debug/jobs"`),
`Depends(verify_api_key)`, `ensure_debug_enabled()` (kapalıyken 404 — ağır iş yapılmadan
önce), pipeline `Depends` ile değil lazy kurulur.

```
GET /api/debug/jobs/{job_id}/bundle -> BundleEnvelopeResponse   # {status:"success", bundle:{...}}
404 -> ErrorResponse   (debug kapalı VEYA job yok)
```

### 3.4 Envelope şekli

```jsonc
{ "status": "success",
  "bundle": {
    "version": "1.0",
    "job_id": "…",
    "job":    { "status", "dialect", "error_code",
                "has_natural_query": true, "has_excel_input": false, "result_sql_present": true },
    "trace":  { /* redakte end_to_end trace (yapısal, hash'li) — null olabilir */ },
    "sql":    { "generated_sql": "…", "last_generated_sql": "…", "sql_valid": true,
                "attempts": [ … ], "sql_validation_errors": [ … ] },   // redakte debug-trace'ten; veya null
    "replay": { /* ReplayResult.to_payload(): version, verdict, baseline_trace_id, retrieval/validation/security delta, notes */ },
    "schema": { "selected_tables": ["…"], "schema_hash": "…", "table_count": 3 },   // veya null
    "meta":   { "bundle_contract_version": "1.0", "replay_contract_version": "…",
                "trace_contract_version": "…", "dialect": "postgres" }
  } }
```
Sınırda **plain string / plain dict** (enum değil) — 27.2.1/27.3/27.4 deseni.

### 3.5 Redaksiyon garantisi

- **Trace bölümü:** mevcut `/api/debug/traces` ile **aynı** iki geçiş (anahtar-tabanlı
  `redact_sensitive_dict` + pattern-tabanlı `redact_sensitive`). `end_to_end` trace zaten
  secret-free; bu geçiş ek güvence.
- **SQL bölümü:** kaynak `DebugTraceAdapter` → `serialize_trace_for_debug` çıktısıdır, yani
  redakte gelir (seçenek 3 niyeti burada gerçekleşir). Projektör yalnız allow-list SQL
  alanlarını alır; ham job satırı (`natural_query`/`result_sql`) ayrıca eklenmez.
- **Schema + meta bölümleri:** **allow-list** — projektör yalnız beyaz-listeli anahtarları
  emit eder; yeni bir alan eklendiğinde varsayılan olarak DIŞARIDA kalır (sızıntı riski
  minimuma iner). Bu allow-list saf katmanda (regex'siz, yapısal) uygulanır.
- Sızıntı testi bir invariant'tır (§4).

### 3.6 Hata yönetimi (27.4 dürüstlük deseni)
- Debug kapalı → **404** (`ensure_debug_enabled`, en başta).
- Job yok → **404** `ErrorResponse` (replay ile aynı mesaj biçimi).
- Trace yok → bundle **yine döner**: `trace: null` + schema mümkünse replay gözleminden;
  değilse `null`. Job + replay yine faydalıdır.
- Trace store hatası → **yutulmaz**, yukarı çıkar → 500 envelope. Bir debug aracı hatayı
  gizlerse yanlış sinyal verir (27.4 `_latest_baseline_payload` yorumuyla aynı ilke).

## 4. Test

- **Saf birim** (`tests/.../debug_bundle/`):
  - `compose_bundle` **determinizmi**: aynı girdi → byte-özdeş `to_payload()`.
  - Projektör **allow-list**: whitelisted olmayan hiçbir anahtar sızmaz; ham
    `natural_query` / `result_sql` bundle'da **yok** (seçenek 3).
  - `project_schema`: `selected_tables` / `schema_hash` çıkarımı; trace yok → replay
    gözleminden türetme; hiçbiri yok → `None`.
  - `project_sql`: redakte debug-trace'ten allow-list SQL alanları; debug trace yok → `None`;
    ham `natural_query`/`result_sql` **yok**.
  - `to_payload` JSON-safe (enum yok, tuple→list).
- **Redaksiyon sızıntı testi** (invariant): trace payload'ında `api_key=…`, `sk-…`,
  `nvapi-…`, `password=…`, `token=…` → bundle çıktısında hepsi `[REDACTED]`.
- **Adaptör** (`bundle_service`): job-yok → `BundleJobNotFound`; trace-yok → `trace:null` +
  schema fallback; trace-store-hatası → yukarı çıkar (yutulmaz).
- **Router / sözleşme**: debug-off → 404; happy-path 200 + envelope şekli;
  `debug_replay` / `debug_traces` sözleşme testleriyle simetrik.
- **Purity guard**: `app.debug_bundle` taze alt süreçte yalnız izinli yüzeyi import eder.
- **Contract snapshot**: `openapi_snapshot.json` + `status_contract_snapshot.json` yeni
  route için **bilinçli** güncellenir; PR body'de gerekçe (contracts runbook).

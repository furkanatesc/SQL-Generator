## §1. Amaç ve kapsam

SQLGen pipeline'ının dağınık per-stage çıktılarını (intent → retrieval/schema →
prompt → generation → validation → security → execution) **tek bir `request_id`
altında korele eden, tipli, immutable, secret-free, I/O-free** bir
**EndToEndTrace contract**'ı tanımlamak. Üretim sorusu: "neden bu SQL üretildi /
neden fail oldu / hangi context seçildi / hangi policy blocked etti?"

Bu sprint, önceki tüm Phase 7 sprint'lerinin **saf-contract** kalıbını izler:
frozen dataclass'lar + contract version sabiti + normalize edici builder'lar +
deterministik testler. **Greenfield değil, bir birleştirme (unification)
işidir** — aşağıdaki mevcut parçaları korele eden bir çatı kurar.

### Mevcut altyapı (yeniden kullanılır, değiştirilmez)
- `app/trace/` (Sprint 25.6): genel `TraceRecord(trace_type, payload, trace_id,
  created_at, job_id, request_id)`, zengin legacy `NL2SQLTrace`, SQLite/memory
  store, `TraceQuery`, debug API, `redaction.py`. **Gerçek I/O yapar
  (persistence).**
- `app/security/audit_event.py` (Sprint 26.6): hash-chain'li `AuditEvent`
  (`category, outcome, severity, reason_code, entry_hash, ...`) + 9 `from_*`
  normalizer. Saf/secret-free; güvenlik domain'ine özgü.
- `app/evaluation/`: per-stage outcome kayıtları —
  `SQLConnectionAwareExecutionOutcome` (status EXECUTED/BLOCKED_LIVE_CONNECTION/
  REJECTED), `SQLExecutionTraceRecord`, `SecurityEvalOutcome`,
  `SQLFailureAnalysisResult` vb.
- `app/middleware/request_logging.py`: `request_id` korelasyonu (header/UUID),
  `app/observability/performance.py`.

### 27.0 ↔ 27.1 sınırı
27.0 = **çatı + 1-2 referans span**. EndToEndTrace zarfı, genel `TraceSpan`
modeli, terminal status/outcome, builder kalıbı ve **iki** referans span
builder'ı (execution + security). Geri kalan stage'lerin (intent, retrieval,
prompt, generation, validation) eksiksiz normalize edici span builder'ları ve
canlı pipeline telçekimi **27.1**'e bırakılır.

## §2. Bağlayıcı invariant'lar (Global Constraints)

1. **Saf, deterministik, secret-free, I/O-free.** Network/DB/clock/random/file
   I/O yok. Clock yok → tüm zamanlamalar (`duration_ms`, `total_duration_ms`)
   **caller-supplied**. ID ve zaman dışarıdan verilir (audit_event kalıbı).
2. Ham SQL/secret **asla** taşınmaz: yalnız `sql_sha256` (64-hex), reason-code /
   symbol adları, ve `app/trace/redaction.py` ile **sanitize edilmiş** hata
   mesajları. NL girdi yalnız `nl_query_sha256` ile referanslanır (ham metin
   yok).
3. Tüm public kayıtlar `@dataclass(frozen=True)`.
4. Contract version sabiti: `END_TO_END_TRACE_CONTRACT_VERSION =
   "end_to_end_trace_v1"`. Her `EndToEndTrace.version` buna eşit olmalı
   (`__post_init__` doğrular).
5. **Driver-isolation korunur.** `app/trace/*` import yüzeyi: stdlib + `app.trace.*` + `app.errors.*`.
   (Sprint 27.2 ile genişletildi: `app.errors` yaprak katmandır, stdlib dışına
   import etmez ve driver taşımaz — invariant'ın amacı olan driver izolasyonu
   korunur. Guard testleri: `tests/errors/test_errors_package_purity.py` ve
   `tests/trace/test_live_trace_assembly.py`.) `to_payload` düz dict döner;
   `json`/`hashlib` çekirdekte gerekmez — sha256'lar caller-supplied, sanitize
   builder'larda `redaction` ile yapılır. Builder'lar **duck-typed**'tır
   (26.11 projektör kalıbı: `Any` alıp attribute okur), bu yüzden
   `app.evaluation` execution tiplerini sert import etmez.
6. **Granülerlik:** bir EndToEndTrace = bir NL→SQL isteğinin tüm yaşam döngüsü
   (retry'lar / çoklu generation denemeleri dahil; retry'lar generation
   span'inin içinde). Deneme-başına trace YOK.
7. **Köprü ama I/O yok:** `EndToEndTrace.to_payload() -> dict` JSON-safe bir
   sözlük üretir; mevcut `TraceRecord.payload` (trace_type="end_to_end") içine
   şema değişmeden konabilir. Gerçek saklama 27.0 kapsamı **dışı**.
8. Yerleşim yalnız `backend/app/trace/`. Testler `backend/tests/trace/`.
9. Commit mesajları: `feat(observability): 27.0 ...`. Claude co-author trailer
   YOK.

## §4. Enum'lar

```python
class TraceStageKind(str, Enum):       # kapalı bilinen küme
    INTENT = "intent"
    RETRIEVAL = "retrieval"
    PROMPT = "prompt"
    GENERATION = "generation"
    VALIDATION = "validation"
    SECURITY = "security"
    EXECUTION = "execution"

class TraceSpanStatus(str, Enum):
    OK = "ok"
    WARNING = "warning"
    ERROR = "error"
    SKIPPED = "skipped"

class TraceTerminalStatus(str, Enum):
    COMPLETED = "completed"
    FAILED = "failed"
    BLOCKED = "blocked"
    REJECTED = "rejected"
```

## §5. Çekirdek kayıtlar

### `TraceSpanDetail` (frozen marker base) + referans detayları

```python
@dataclass(frozen=True)
class TraceSpanDetail:        # boş marker; detay tipleri bunu genişletir
    pass

@dataclass(frozen=True)
class ExecutionSpanDetail(TraceSpanDetail):
    execution_status: str            # "executed" | "blocked_live_connection" | "rejected"
    dialect: str | None = None
    sql_sha256: str | None = None    # ham SQL değil
    row_count: int | None = None
    truncated: bool | None = None
    error_code: str | None = None    # mevcut error taxonomy kodu
    error_message: str | None = None # sanitize edilmiş

@dataclass(frozen=True)
class SecurityCheck:
    category: str          # AuditCategory.value
    outcome: str           # AuditOutcome.value
    severity: str          # AuditSeverity.value
    reason_code: str | None = None
    audit_entry_hash: str | None = None   # hash-chain'e korelasyon işaretçisi

@dataclass(frozen=True)
class SecuritySpanDetail(TraceSpanDetail):
    checks: tuple[SecurityCheck, ...] = ()
```

### `TraceSpan` (frozen) — hibrit modelin kalbi

```python
@dataclass(frozen=True)
class TraceSpan:
    stage: TraceStageKind
    status: TraceSpanStatus
    duration_ms: float | None = None          # caller-supplied
    detail: TraceSpanDetail | None = None      # tipli alt-kayıt (bilinen aşama)
    attributes: Mapping[str, str] = field(default_factory=dict)  # secret-free kaçış kapısı
```
`__post_init__`: `attributes` değerleri str olmalı (secret-free; ham obje değil).

### `EndToEndTrace` (frozen) — zarf

```python
@dataclass(frozen=True)
class EndToEndTrace:
    version: str
    trace_id: str
    request_id: str
    terminal_status: TraceTerminalStatus
    spans: tuple[TraceSpan, ...]
    terminal_stage: TraceStageKind | None = None
    job_id: str | None = None
    dialect: str | None = None
    nl_query_sha256: str | None = None
    total_duration_ms: float | None = None
```

**`__post_init__` invariant'ları:**
- `version == END_TO_END_TRACE_CONTRACT_VERSION` değilse → `EndToEndTraceError`.
- `trace_id` / `request_id` boş veya non-string → `EndToEndTraceError`.
- `spans` içinde aynı `stage` >1 kez → `EndToEndTraceError` (stage başına ≤1 span).
- `terminal_status ∈ {FAILED, BLOCKED, REJECTED}` ise: `terminal_stage`
  set olmalı, o stage'in span'i mevcut olmalı ve span status'u `ERROR` olmalı →
  aksi halde `EndToEndTraceError`.
- `terminal_status == COMPLETED` ise hiçbir span `ERROR` olmamalı.

**`to_payload(self) -> dict`:** tüm alanları (enum'lar `.value`, span'ler ve
detaylar iç içe dict'ler olarak) JSON-safe bir sözlüğe serialize eder.
`json.dumps(trace.to_payload())` hatasız çalışmalı ve ham SQL/secret içermemeli.

## §6. Türetme ve assembler (saf, `end_to_end_trace.py`)

### `derive_terminal(spans) -> tuple[TraceTerminalStatus, TraceStageKind | None]`
Saf kural, sıralı tarama; **öncelik yukarıdan aşağı:**
1. EXECUTION span'i var ve `detail.execution_status == "blocked_live_connection"`
   → `(BLOCKED, EXECUTION)`.
2. EXECUTION span'i var ve `detail.execution_status == "rejected"`
   → `(REJECTED, EXECUTION)`.
3. Aksi halde sırayla ilk `status == ERROR` span'i → `(FAILED, o_stage)`.
4. Hiç ERROR yoksa → `(COMPLETED, son_span.stage)` (span yoksa
   `terminal_stage = None`).

> Öncelik notu: execution'ın blocked/rejected durumu, daha erken bir ERROR
> span'inin önüne geçer — terminal status'ta execution sonucu otoritatiftir.

### `build_end_to_end_trace(*, trace_id, request_id, spans, job_id=None, dialect=None, nl_query_sha256=None, total_duration_ms=None) -> EndToEndTrace`
Ana giriş noktası: `derive_terminal(spans)` ile `(terminal_status,
terminal_stage)` hesaplar, `EndToEndTrace`'i kurar (`version` sabiti gömülü),
`__post_init__` doğrulamasından geçirir, frozen trace döner.

## §7. Builder'lar (duck-typed, `end_to_end_trace_builders.py`)

### `build_execution_span(outcome, *, duration_ms=None) -> TraceSpan`
Duck-typed `SQLConnectionAwareExecutionOutcome` okur:
- `.status` (EXECUTED / BLOCKED_LIVE_CONNECTION / REJECTED) — `.value` veya
  enum; builder her ikisini de tolere eder (str'e indirger).
- `.plan.effective_dialect`, `.execution_result.{sql_sha256, row_count,
  truncated}`, `.error`, `.warnings`.

Status eşleme → `TraceSpanStatus`:
- `EXECUTED` → `OK` (warnings varsa `WARNING`)
- `BLOCKED_LIVE_CONNECTION` → `ERROR`
- `REJECTED` → `ERROR`

`ExecutionSpanDetail` doldurur (`execution_status` = status'un str biçimi); varsa
hata mesajını `redaction.redact_sensitive_text` ile sanitize eder, `error_code`'u
varsa `SqlExecutionError.code`'dan / outcome'dan alır. Tanınmayan/eksik status →
net mesajlı `EndToEndTraceError`.

### `build_security_span(audit_events) -> TraceSpan`
Duck-typed `AuditEvent` dizisi okur. Her event → `SecurityCheck(category,
outcome, severity, reason_code, audit_entry_hash=entry_hash)`.

Span status türetme (tüm event'ler üzerinden):
- Herhangi `outcome ∈ {DENIED, ERROR}` → `ERROR`
- Aksi, herhangi `outcome ∈ {FLAGGED, REQUIRES_APPROVAL}` → `WARNING`
- Aksi (hepsi `ALLOWED`) → `OK`
- **Boş dizi → `SKIPPED`** (güvenlik aşaması koşmadı), `detail.checks = ()`.

> 27.1 ileride aynı duck-typed kalıpla `build_intent_span`,
> `build_retrieval_span`, `build_prompt_span`, `build_generation_span`,
> `build_validation_span` ekleyecek.

## §8. Hata yönetimi

- `EndToEndTraceError(Exception)` — tüm contract/wiring ihlalleri.
- Kayıt-kurma (`__post_init__`) ihlalleri ve assembler doğrulaması §5'te.
- Builder'lar yapısal olarak geçersiz girdide (tanınmayan status, eksik zorunlu
  attribute) **açıkça** `EndToEndTraceError` yükseltir — duck-typed
  `AttributeError`'ı sessizce yutmaz.
- Case mismatch / policy DENY gibi **alan sonuçları hata değildir**: bunlar span
  status'una (ERROR/WARNING) ve terminal status'a normalize edilir, exception
  fırlatılmaz.

## §9. Test matrisi (TDD)

**`test_end_to_end_trace.py`:**
- Invariant: version mismatch / boş trace_id / boş request_id / tekrar stage /
  terminal-span tutarsızlığı (FAILED ama terminal_stage span'i ERROR değil) /
  COMPLETED ama ERROR span var → hepsi `EndToEndTraceError`.
- `derive_terminal`: completed (son span); failed-at-first-error;
  blocked@execution; rejected@execution; **öncelik** (execution blocked, daha
  erken bir validation ERROR span'inin önüne geçer).
- `build_end_to_end_trace`: happy-path assemble + terminal türetme + frozen.
- `to_payload`: `json.dumps` round-trip; enum'lar `.value`; iç içe span/detay
  dict'leri; secret-free.
- **Secret-free testi:** sahte secret-görünümlü string (`password=...`,
  `sk-...`) içeren bir `attributes` / sanitize edilmemiş error → trace ve
  payload'da ham görünmez.
- **Driver-isolation testi:** `import app.trace.end_to_end_trace` sonrası
  `app.evaluation.connection_abstraction` ve bilinen DB driver modülleri
  `sys.modules`'da yok (26.10/26.11 kalıbı).

**`test_end_to_end_trace_builders.py`:**
- `build_execution_span`: executed→OK (+warnings→WARNING); blocked→ERROR;
  rejected→ERROR; `ExecutionSpanDetail` alanları doğru; hata sanitize; ham SQL
  yok (yalnız sha256); tanınmayan status → `EndToEndTraceError`.
- `build_security_span`: hepsi-allowed→OK; bir denied→ERROR; flagged→WARNING;
  boş→SKIPPED; çoklu event tek span'de toplanır; `entry_hash` `SecurityCheck`'e
  taşınır.
- Builder'lar gerçek (fake değil) hafif duck-typed nesnelerle test edilir
  (basit `SimpleNamespace`/küçük frozen stub'lar) — gerçek davranış doğrulanır.

## §10. Kabul kriterleri
1. `import app.trace.end_to_end_trace` driver/`app.evaluation` yüklemeden başarılı.
2. Tüm yeni testler + `backend/tests/trace/` dizini yeşil.
3. Tam backend suite regresyon kapısı: önceki baseline (1965 passed / 9 skipped)
   + yeni testler, 0 failed.
4. `EndToEndTrace.to_payload()` JSON-serializable ve secret-free.
5. `build_execution_span` / `build_security_span` mevcut
   `SQLConnectionAwareExecutionOutcome` / `AuditEvent` şekillerinden doğru span
   üretir (duck-typed).

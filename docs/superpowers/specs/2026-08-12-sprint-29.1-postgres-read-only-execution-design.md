# Sprint 29.1 — PostgreSQL Read-Only Execution (Design)

**Phase:** 10 — Real Database Adapter Layer
**Date:** 2026-08-12
**Predecessors:** 25.8 (local-Docker read-only adapter, inert), 29.0 (Docker introspection adapter + connection resolver)

## Amaç

25.8'in gerçek `SELECT` çalıştırabilen ama **inert** (`connection=None` → `NOT_IMPLEMENTED`)
PostgreSQL adapter'ını, mevcut **dialect-agnostik execution kontratına**
(`SQLDatabaseExecutionAdapter` / `SQLDatabaseExecutionResult`, `multi_database_execution.py`)
bağlı, **kullanılabilir bir Postgres execution adapter'ına** dönüştürmek.

Sınırlar (bilinçli, korunur):

- **Local-Docker-only, read-only.** Uzak/production connection yok.
- **Driver-izole.** Modül import-time'da `psycopg2` yüklemez (lazy, 25.8 üzerinden);
  `app.evaluation` içinde kalır.
- **Yan-etkisiz.** Hiçbir persistence/store yazımı yok.
- **Canlı HTTP pipeline'a değmez.** `/api/jobs` request path wiring bilinçli olarak
  Phase 11'e (30.2 Connection Registry / 30.4 Query Run API) ertelenir.

> **25.x vs Phase 10 rol ayrımı (PLANNED-SPRINTS):** 25.8 = "iskele" (contract stub +
> local Docker smoke). 29.1 = o iskelenin **gerçek, ortak kontrata bağlı execution**
> hâli. Tekrar değil; 25.8 inert adapter'ı ilk kez üretilebilir bir seam'e oturur.

## Mimari

### Mevcut seam (yeniden kullanılır — yeni kontrat icat edilmez)

`backend/app/evaluation/multi_database_execution.py` zaten dialect-agnostik execution
kontratını barındırıyor:

- `SQLDatabaseDialect` enum → `SQLITE` / `POSTGRESQL` / `ORACLE` (POSTGRESQL zaten var)
- `SQLDatabaseExecutionAdapter` (ABC): `dialect`, `execute(request)`, `capabilities()`
- `SQLDatabaseExecutionRequest` / `SQLDatabaseExecutionConfig` / `SQLDatabaseExecutionResult`
- `SQLiteDatabaseExecutionAdapter` (mevcut somut adapter) + `SQLDatabaseExecutionRouter`

29.1, bu kontrata **ikinci somut adapter** ekler. `SQLDatabaseExecutionResult` = kullanıcı
kararındaki "ince dialect-agnostik outcome" — yeni izole bir outcome tipi yaratılmaz.

### Ana bileşen — yeni modül `app/evaluation/postgres_execution_adapter.py`

`PostgresDatabaseExecutionAdapter(SQLDatabaseExecutionAdapter)`:

- `dialect` → `SQLDatabaseDialect.POSTGRESQL`
- `capabilities()` → `(SQLExecutionAdapterCapability.CONNECTION_REF, SQLExecutionAdapterCapability.READ_ONLY)`
- `__init__(connection_resolver=resolve_local_docker_connection)` — 29.0 resolver default;
  test için inject edilebilir (env-bağımsız birim test).
- `execute(request: SQLDatabaseExecutionRequest) -> SQLDatabaseExecutionResult`:
  1. **Doğrula:** `request.dialect == POSTGRESQL`; `connection_ref` dolu **ve** `fixture_ref`
     `None` (Postgres fixture desteklemez); `config.execution_mode == READ_ONLY`
     (EXPLAIN_ONLY → 29.2). İhlal → `SQLMultiDatabaseExecutionContractError` (SQLite
     adapter'ın davranış paritesi).
  2. **Connection çöz:** `connection_resolver()`; **`None` → graceful** dönüş —
     `SQLDatabaseExecutionResult(execution_error="No local Docker PostgreSQL connection available", row_count=0, rows=())`.
     Raise **etmez** → docker'sız CI'da entegrasyon testleri temiz safe-skip alır ve
     runtime çağrı da güvenle boş sonuç görür.
  3. **25.8'e delege:** `SQLPostgresAdapterExecutionRequest` kur (config eşlemesi:
     `timeout_seconds`, `max_rows`, `execution_mode="read_only"`; `case_id`/`sql` taşınır),
     `SQLPostgresAdapterContract(connection=conn).execute(...)` çağır.
  4. **Normalize et** → `SQLDatabaseExecutionResult`:
     - `EXECUTED` → pozisyonel satırlar + kolon adları **dict satırlara** eşlenir
       (aşağıya bkz.); `truncated`/`warnings`/`duration_ms` taşınır; `execution_error=None`.
     - `REJECTED` / `EXECUTION_ERROR` / `NOT_IMPLEMENTED` → `rows=()`, `row_count=0`,
       `execution_error` = 25.8'in (zaten secret-free/sanitize edilmiş) `error` alanı.

`execute` içinde ham driver hatası yakalanmaz/yeniden şekillendirilmez — 25.8 zaten
credential-free sanitize ediyor; normalize sadece alan eşlemesi yapar.

### Zorunlu küçük değişiklik — 25.8 `postgres_adapter.py` (geriye uyumlu)

`SQLDatabaseExecutionResult.rows` **dict** ister (`Tuple[Mapping[str, Any], ...]`), ama
25.8 `SQLPostgresAdapterExecutionResult.rows` pozisyonel `Tuple[Tuple[...], ...]` ve
**kolon adlarını yakalamıyor**. Gerçek kolon adlı dict üretmek için 25.8'e geriye-uyumlu
ekleme:

- `SQLPostgresAdapterExecutionResult`'a `columns: Tuple[str, ...] = ()` alanı (varsayılan
  boş → mevcut çağıranlar/testler kırılmaz; `to_dict`'e `"columns"` eklenir).
- `_execute_select` içinde başarılı fetch'ten sonra `cur.description`'dan kolon adları
  okunur (`tuple(d[0] for d in cur.description)` — `description None` ise `()`), sonuca
  konur. Kolon adları kimlik bilgisi değildir; sanitize kapsamı dışında.

Yeni adapter dict satırı `dict(zip(columns, positional_row))` ile kurar. Kolon sayısı
satır uzunluğuyla eşleşmezse (savunma) `col_0..col_n` fallback adı kullanılır ve bir
warning eklenir (sessiz bozulma yok).

### Router

Merkezî router yok — `execution_accuracy.py` router'ı ad-hoc `(sqlite,)` ile kuruyor.
29.1 yeni adapter'ı canlı bir yere **zorla eklemez**; adapter'ın router'a takılabilirliğini
(`SQLDatabaseExecutionRouter(adapters=(sqlite_adapter, postgres_adapter))` → dialect
dispatch) testte gösterir. Canlı router/registry wiring 30.x'e kalır.

## Güvenlik & değişmezler

- **Read-only enforcement:** 25.8'in mevcut üç katmanı korunur (string-level SELECT gate
  = 26.2 shared contract, `default_transaction_read_only=on`, `statement_timeout`).
  26.3 risk classifier / 26.4 sensitive gate wiring **kapsam dışı** (kullanıcı kararı).
- **Driver-isolation invariant:** yeni modülün import'u hiçbir DB driver/socket yüklemez
  (subprocess import testi, 25.8/29.0 precedent'i).
- **Secret-free:** sonuçlar yalnız `sql_sha256` + sanitize edilmiş `execution_error` +
  kolon adları + satır değerleri taşır; connection detayı (host/user/password) asla.
- **Determinizm:** adapter `datetime.now()`/rasgelelik kullanmaz; `duration_ms` monotonic
  ölçümdür (SQLite adapter paritesi).

## Test planı

**Unit (docker'sız, her CI koşusunda):**
- `dialect == POSTGRESQL`, `capabilities()` = (CONNECTION_REF, READ_ONLY)
- `connection_ref` zorunlu; `fixture_ref` verilirse reddedilir; `EXPLAIN_ONLY` reddedilir
- `connection_resolver` `None` döndürünce → graceful `execution_error`'lı sonuç (raise yok)
- Normalizasyon eşlemesi: sahte bir 25.8 sonucu inject edilip her statüs
  (`EXECUTED`/`REJECTED`/`EXECUTION_ERROR`/`NOT_IMPLEMENTED`) → doğru `SQLDatabaseExecutionResult`
- `EXECUTED` dict-row eşlemesi: kolon adları ↔ değerler; kolon/uzunluk uyuşmazlığında
  fallback + warning
- Read-only ihlali (`INSERT`/multi-statement) → 25.8 `REJECTED` → `execution_error`
- Import-time driver-isolation (subprocess, `psycopg2`/socket yüklenmez)
- 25.8: `columns` alanı geriye uyumlu (varsayılan `()`; `to_dict` içerir)

**Gated integration (docker, safe-skip; CI'da seeded Postgres ile koşar):**
- Seeded şemada (`customers`/`orders`/...) gerçek `SELECT` → gerçek kolon adlı dict satırlar
- Çok-tablolu `JOIN` (29.0 seed'i üzerinden) doğru satırlar
- `max_rows` truncation → `truncated=True` + warning
- Çok kısa `timeout` → `execution_error` (timeout mesajı), raise yok

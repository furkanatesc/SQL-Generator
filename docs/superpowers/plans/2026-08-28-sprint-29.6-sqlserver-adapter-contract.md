# Sprint 29.6 — SQL Server Adapter Contract — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Deliver a real, local-Docker-only, read-only SQL Server execution path (`pymssql`, driver-isolated, standalone/inert) plus its full test harness (seed + applier that also provisions a read-only login + docker-compose + a live CI job), mirroring MySQL 29.5 (contract adapter + harness) in one sprint with SQL Server deltas.

**Architecture:** Add `SQLSERVER` to the shared dialect enum, then mirror the **MySQL 29.5** modules with SQL-Server-specific deltas: `mssql_adapter.py` (3 defense layers — shared string gate → lazy `pymssql` → read-only login + query-timeout + always-rollback), `mssql_connection_resolver.py`, `mssql_execution_adapter.py` (shared-contract bridge), `mssql_seed.py` (pure applier that also creates the DB and a `db_datareader`-only login). Add a SQL Server seed, an `mcr.microsoft.com/mssql/server:2022-latest` compose service, and a separate additive `sqlserver-integration` CI job. No live production pipeline wiring.

**Tech Stack:** Python 3.11, pytest (markers `integration`, `sqlserver`), `pymssql==2.3.2` (FreeTDS bundled in the wheel — no system ODBC), `mcr.microsoft.com/mssql/server:2022-latest`, Docker Compose, GitHub Actions.

**Spec:** `docs/superpowers/specs/2026-08-28-sprint-29.6-sqlserver-adapter-contract-design.md`

## Global Constraints

- **Mirror the MySQL 29.5 modules.** Each core file adapts its MySQL counterpart (`mysql_adapter.py` / `mysql_connection_resolver.py` / `mysql_execution_adapter.py` / `mysql_seed.py`) via a mechanical rename plus the named behavioral deltas. Read the MySQL file first; do not invent a new structure.
- **Mechanical rename map:** `MySQL`→`MSSQL`, `mysql`→`mssql`, `MYSQL`→`MSSQL`, `pymysql`→`pymssql`, contract version `sql_mysql_adapter_contract_v1`→`sql_mssql_adapter_contract_v1`, capability flag `supports_mysql_execution`→`supports_mssql_execution`. **Except:** dialect string `"mysql"`→`"sqlserver"` (public value) and pytest marker `mysql`→`sqlserver`. Code token is `mssql`/`MSSQL` throughout; the dialect **value** and **marker** are `sqlserver`. This value-vs-token split is deliberate (spec §1) — do not "fix" it.
- **SQL Server behavioral deltas (load-bearing):** there is **no server-side read-only transaction** — read-only is enforced by (a) the L1 string gate and (b) connecting as a **read-only login** (`db_datareader` role only), with an always-`rollback()` backstop. So `_execute_select` issues **no** `SET SESSION`/`START TRANSACTION` pre-statements (unlike MySQL/Oracle) — it just `cur.execute(sql)`. Statement timeout is the **driver query timeout** passed at connect: `pymssql.connect(server=host, port=port, user=user, password=password, database=database, login_timeout=<ceil(s)>, timeout=<ceil(s)>)`. Connection carries `server`/`port`/`database` (dataclass fields still `host`/`port`/`database`/`user`/`password`). `_sanitize_mssql_error` maps a query timeout (DB-Library code 20003/20004, or "timeout" in the message/type name) to a distinct message and otherwise returns `f"SQL Server execution failed ({type(exc).__name__})."` — never leaking host/user/password/database/server.
- **Identifier case:** SQL Server returns identifier/alias case as written; all seed tables/columns and all test SQL are lowercase; seeded-test column-key assertions use the alias case as written (lowercase) — same as MySQL.
- **Two credential sets:** the adapter/resolver use the **read-only login** (`MSSQL_TEST_USER`/`MSSQL_TEST_PASSWORD`, default `sqlgen_ro`/`Sqlgen_Ro0!Pass`); the seed applier uses an **admin** connection (`MSSQL_TEST_ADMIN_USER`/`MSSQL_TEST_ADMIN_PASSWORD`, default `sa`/`Sqlgen_Str0ng!Pass`) to create the database, apply the seed, and create the read-only login. The `mcr` image does **not** auto-create a database from env, so the applier creates it.
- **Driver isolation:** no module imports `pymssql` (or `_mssql`/`sqlalchemy`/`pyodbc`) at top level — `pymssql` imports lazily inside execution/`main()` paths only. Subprocess tests enforce this.
- **`__init__.py` exports:** export the `mssql_adapter` public surface from `app/evaluation/__init__.py` (mirroring how `mysql_adapter` is exported). Do NOT export `mssql_connection_resolver`, `mssql_execution_adapter`, or `mssql_seed` (harness-only).
- **No new execution behavior in the shared contract** beyond adding the `SQLSERVER` enum member.
- **Commit messages:** plain, no Claude/co-author trailer. Prefixes `feat(29.6):` / `test(29.6):` / `ci(29.6):` / `docs(29.6):`.
- **Before running the full suite:** ensure venv `fastapi==0.115.12` (see memory `sqlgen-fastapi-pin-drift`) or the `api_surface` test fails spuriously.

```python
# pymssql/DB-Library query timeout surfaces as error 20003 (DBPROCESS timed out); 20004 read error.
_MSSQL_TIMEOUT_CODES = (20003, 20004)


def _sanitize_mssql_error(exc: Exception) -> str:
    """Credential-free, deterministic message. Timeouts get a distinct message."""
    code = None
    try:
        code = exc.args[0]
    except (IndexError, AttributeError):
        code = None
    if isinstance(code, int) and code in _MSSQL_TIMEOUT_CODES:
        return "SQL Server execution timed out (query timeout exceeded)."
    if "timed out" in str(exc).lower() or "timeout" in type(exc).__name__.lower():
        return "SQL Server execution timed out (query timeout exceeded)."
    return f"SQL Server execution failed ({type(exc).__name__})."
```

```python
"""Sprint 29.6 — Pure local-Docker SQL Server connection resolver.

Single, reusable place a SQLMSSQLLocalDockerConnection (the read-only login)
is built from the MSSQL_TEST_* env contract. Never connects and never raises:
any invalid / remote / missing value yields None (inert), matching the
adapter's connection=None inert path.
"""

import os
from typing import Mapping, Optional

from app.evaluation.mssql_adapter import (
    SQLMSSQLAdapterContractError,
    SQLMSSQLLocalDockerConnection,
)

MSSQL_CONNECTION_RESOLVER_VERSION = "v1"


def resolve_local_docker_connection(
    env: Optional[Mapping[str, str]] = None,
) -> Optional[SQLMSSQLLocalDockerConnection]:
    src = os.environ if env is None else env
    host = src.get("MSSQL_TEST_HOST", "localhost")
    port_raw = src.get("MSSQL_TEST_PORT", "1433")
    database = src.get("MSSQL_TEST_DB", "sqlgen_test")
    user = src.get("MSSQL_TEST_USER", "sqlgen_ro")
    password = src.get("MSSQL_TEST_PASSWORD", "Sqlgen_Ro0!Pass")

    try:
        port = int(port_raw)
    except (TypeError, ValueError):
        return None

    try:
        return SQLMSSQLLocalDockerConnection(
            host=host, port=port, database=database, user=user, password=password,
        )
    except (SQLMSSQLAdapterContractError, ValueError):
        return None
```

```python
_IDENT_RE = re.compile(r"^[A-Za-z0-9_]+$")


def _validate_identifier(name: str) -> str:
    if not _IDENT_RE.match(name or ""):
        raise ValueError("SQL Server identifier must be alphanumeric/underscore")
    return name


def readonly_login_ddl(login: str, password: str, database: str) -> tuple:
    """Idempotent DDL to create a db_datareader-only login/user. Pure (no I/O).

    Identifiers are validated (alnum/underscore); the password must not contain
    a single quote (values come from trusted CI env, not user input).
    """
    _validate_identifier(login)
    _validate_identifier(database)
    if "'" in password:
        raise ValueError("read-only password must not contain a single quote")
    return (
        f"IF NOT EXISTS (SELECT 1 FROM sys.server_principals WHERE name = N'{login}') "
        f"CREATE LOGIN [{login}] WITH PASSWORD = N'{password}', CHECK_POLICY = OFF;",
        f"IF NOT EXISTS (SELECT 1 FROM sys.database_principals WHERE name = N'{login}') "
        f"CREATE USER [{login}] FOR LOGIN [{login}];",
        f"ALTER ROLE db_datareader ADD MEMBER [{login}];",
    )


def _connect_with_retry(pymssql, *, attempts=30, delay=2.0, **kwargs):
    last = None
    for _ in range(attempts):
        try:
            return pymssql.connect(**kwargs)
        except Exception as exc:  # noqa: BLE001 - readiness wait
            last = exc
            time.sleep(delay)
    raise last


def _exec(conn, sql: str) -> None:
    cur = conn.cursor()
    try:
        cur.execute(sql)
    finally:
        cur.close()


def main(argv: Optional[Sequence[str]] = None) -> int:
    import pymssql  # lazy — driver isolation

    host = os.environ.get("MSSQL_TEST_HOST", "localhost")
    port = int(os.environ.get("MSSQL_TEST_PORT", "1433"))
    database = os.environ.get("MSSQL_TEST_DB", "sqlgen_test")
    admin_user = os.environ.get("MSSQL_TEST_ADMIN_USER", "sa")
    admin_password = os.environ.get("MSSQL_TEST_ADMIN_PASSWORD", "Sqlgen_Str0ng!Pass")
    ro_user = os.environ.get("MSSQL_TEST_USER", "sqlgen_ro")
    ro_password = os.environ.get("MSSQL_TEST_PASSWORD", "Sqlgen_Ro0!Pass")

    create_login, create_user, grant_role = readonly_login_ddl(ro_user, ro_password, database)

    # Phase A: master — wait for readiness, create DB + RO login (autocommit for DDL).
    master = _connect_with_retry(
        pymssql, server=host, port=port, user=admin_user,
        password=admin_password, database="master", login_timeout=5,
    )
    try:
        master.autocommit(True)
        _exec(master, f"IF DB_ID(N'{database}') IS NULL CREATE DATABASE [{database}];")
        _exec(master, create_login)
    finally:
        master.close()

    # Phase B: sqlgen_test — apply the seed (transactional), then the RO user + role (autocommit).
    seed_path = os.path.join(os.path.dirname(__file__), "..", "..", "tests", "fixtures", "mssql", "seed.sql")
    with open(os.path.abspath(seed_path), "r", encoding="utf-8") as fh:
        seed_sql = fh.read()

    conn = pymssql.connect(server=host, port=port, user=admin_user, password=admin_password, database=database)
    try:
        count = apply_seed(conn, seed_sql)
        conn.autocommit(True)
        _exec(conn, create_user)
        _exec(conn, grant_role)
    finally:
        conn.close()

    print(f"applied {count} statements; provisioned read-only login {ro_user}")
    return 0


if __name__ == "__main__":  # pragma: no cover
    raise SystemExit(main())
```

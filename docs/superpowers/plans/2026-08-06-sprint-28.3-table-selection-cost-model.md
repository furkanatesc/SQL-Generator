# Table Selection Cost Model (Sprint 28.3) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace `select_schema_context`'s hardcoded additive relevance score + flat top-K with a config-driven benefit-vs-cost budget model: named tunable weights, a per-table cost function, and benefit-density greedy selection under a conservatively-calibrated cost budget.

**Architecture:** A new pure module `table_selection_cost.py` holds a frozen `TableSelectionCostModel` (named benefit weights + cost weights + budget), `table_cost`, `fk_counts`, and a tolerant `from_config` parser (27.8 `llm_pricing` pattern). `select_schema_context` gains an injected `cost_model` param (pure-leaf preserved), scores with the model's weights, and selects by benefit-density greedy under the cost budget with exact-match focus tables guaranteed first and `max_tables` as a secondary cap. The dirty config load happens in `sql_pipeline.py`. Conservative default budget keeps production ≈ current top-8.

**Tech Stack:** Python 3.11 (CI)/3.12 (local), pydantic 2.13.4 (pinned), pytest, stdlib. Benchmark package `backend/benchmarks/` (v3→v4).

## Global Constraints

- **Purity:** `table_selection_cost.py` and `schema_context_selector.py` stay stdlib + pydantic only (no datetime/perf_counter/random/I/O). The cost model is INJECTED into the selector; config loading is the pipeline's (dirty) job — mirrors 28.1 `probe` / 28.2 `node_budget` injection.
- **Behavior-preservation of unrelated params:** `probe` (28.1) and `node_budget` (28.2) params and their behavior are UNCHANGED. 28.3 only changes table selection.
- **Determinism:** all scoring, cost, and greedy selection are seed-free deterministic. Greedy tie-break is exactly `(-density, cost, name)`; forced-focus tie-break is `(-benefit, name)`.
- **No magic numbers in the selector:** every relevance weight comes from `cost_model` (no literal 100.0/60.0/... left in `schema_context_selector.py`).
- **Golden eval is constraint-based** (`required_tables` ⊆ selected, `forbidden_tables` ∩ selected = ∅, `required_join_edges` present, `expect_fallback`) — NOT exact-set match. Conservative calibration should keep it green; any change is curated with justification (no silent drop).
- **No Claude commit trailer**; plain ASCII commit bodies; `§` only in prose.
- **Run tests from** `backend/` (`cd backend && python -m pytest ...`).
- **Config key:** `table_selection_cost_model` (read via `app.database.get_config`, tolerant JSON parse; absent/invalid → `DEFAULT_COST_MODEL`).

```python
"""Table selection cost model — PURE (Sprint 28.3).

Named relevance weights + a per-table cost function for benefit-vs-cost
budget selection. Injected into select_schema_context (no I/O here).
from_config tolerantly parses the configs 'table_selection_cost_model' JSON
(27.8 llm_pricing pattern): invalid/missing -> DEFAULT_COST_MODEL.
"""
import json
from pydantic import BaseModel, ConfigDict

_KNOWN_FIELDS = {
    "exact_table", "singular_plural_table", "table_token_overlap",
    "exact_column", "column_token_overlap", "explicit_neighbor", "implicit_neighbor",
    "w_base", "w_col", "w_fk", "cost_budget",
}


class TableSelectionCostModel(BaseModel):
    model_config = ConfigDict(frozen=True, extra="forbid")
    exact_table: float = 100.0
    singular_plural_table: float = 60.0
    table_token_overlap: float = 40.0
    exact_column: float = 80.0
    column_token_overlap: float = 30.0
    explicit_neighbor: float = 20.0
    implicit_neighbor: float = 10.0
    w_base: float = 1.0
    w_col: float = 1.0
    w_fk: float = 0.0
    cost_budget: float = 100.0  # PROVISIONAL — calibrated on the golden schema in Task 4


DEFAULT_COST_MODEL = TableSelectionCostModel()


def table_cost(n_columns: int, n_fks: int, model: TableSelectionCostModel) -> float:
    return model.w_base + model.w_col * n_columns + model.w_fk * n_fks


def fk_counts(schema) -> dict:
    """FK-owner (source_table) relationship count per table — deterministic."""
    counts: dict = {}
    for rel in schema.relationships:
        counts[rel.source_table] = counts.get(rel.source_table, 0) + 1
    return counts


def _is_number(v) -> bool:
    return isinstance(v, (int, float)) and not isinstance(v, bool)


def from_config(raw) -> TableSelectionCostModel:
    if not raw:
        return DEFAULT_COST_MODEL
    try:
        data = json.loads(raw)
    except (ValueError, TypeError):
        return DEFAULT_COST_MODEL
    if not isinstance(data, dict):
        return DEFAULT_COST_MODEL
    overrides = {k: float(v) for k, v in data.items()
                 if k in _KNOWN_FIELDS and _is_number(v)}
    return TableSelectionCostModel(**overrides)
```

- Replace the flat top-K block (current lines ~113-120) with the greedy below. Everything else (probe, fallback, join-path discovery, node_budget, return) is unchanged except the two new field values and reading `score`.
- Greedy rule (skip-and-continue fill): exact-match focus tables first (by `-benefit, name`) up to `max_tables`; then remaining scored tables by `(-density, cost, name)` where `density = benefit/cost` (or `inf` if `cost <= 0`); add each that fits (`total_cost + cost <= cost_model.cost_budget`) until `max_tables` reached; if a candidate does not fit, skip it, set `budget_exhausted = True`, and continue trying cheaper ones.

    col_counts = {t.name: len(t.columns) for t in schema.tables}
    fk_map = fk_counts(schema)

    def _cost(name: str) -> float:
        return table_cost(col_counts.get(name, 0), fk_map.get(name, 0), cost_model)

    def _density(name: str, benefit: float) -> float:
        c = _cost(name)
        return float("inf") if c <= 0 else benefit / c

    scored = [(n, s) for n, s in table_scores.items() if s > 0]
    forced = [(n, s) for n, s in scored if "exact_table_match" in table_reasons[n]]
    rest = [(n, s) for n, s in scored if "exact_table_match" not in table_reasons[n]]
    forced.sort(key=lambda ns: (-ns[1], ns[0]))
    rest.sort(key=lambda ns: (-_density(ns[0], ns[1]), _cost(ns[0]), ns[0]))

    selected_tables = []
    total_cost = 0.0
    budget_exhausted = False

    def _append(name: str, benefit: float):
        nonlocal total_cost
        c = _cost(name)
        selected_tables.append(SelectedTable(
            table_name=name, score=benefit, reasons=table_reasons[name], cost=c))
        total_cost += c

    for name, benefit in forced:
        if len(selected_tables) >= max_tables:
            break
        _append(name, benefit)  # exact-match focus guaranteed (ignores budget)

    for name, benefit in rest:
        if len(selected_tables) >= max_tables:
            break
        if total_cost + _cost(name) > cost_model.cost_budget:
            budget_exhausted = True
            continue
        _append(name, benefit)

### Task 1: Inline copy feedback + clipboard hardening + type fix

**File:** Modify `frontend/src/components/ChatView.vue`.

- [ ] **Step 1: Script — remove unused import + add per-message copy state + safe async copy**

Remove `import type { Job } from '../services/api';` (unused).

Replace `copyToClipboard`:
```ts
const copiedMessageId = ref<number | null>(null);
const copyErrorMessageId = ref<number | null>(null);
let copyResetTimer: ReturnType<typeof setTimeout> | null = null;

const copyToClipboard = async (sql: string | undefined, messageId: number) => {
  if (!sql) return;
  if (copyResetTimer) { clearTimeout(copyResetTimer); copyResetTimer = null; }
  try {
    await navigator.clipboard.writeText(sql);
    copiedMessageId.value = messageId;
    copyErrorMessageId.value = null;
  } catch {
    copyErrorMessageId.value = messageId;
    copiedMessageId.value = null;
  }
  copyResetTimer = setTimeout(() => {
    copiedMessageId.value = null;
    copyErrorMessageId.value = null;
    copyResetTimer = null;
  }, 1600);
};
```
Clear the timer on unmount (extend the existing `onUnmounted`): `if (copyResetTimer) clearTimeout(copyResetTimer);`.

- [ ] **Step 2: Template — swap the copy button for the stateful version**

Replace the SQL-block copy button with a state-driven label/icon (default / copied / error), keyed by `msg.id`, with `aria-live`:

# Relationship Confidence Scoring (Sprint 28.4) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make the cost-model's neighbor benefit reflect relationship confidence — unify `explicit_neighbor`/`implicit_neighbor` into a single `neighbor_base × effective_confidence` (explicit/custom `None`→1.0, implicit 0.60-0.90), with fuzzy neighbors opt-in via a config flag.

**Architecture:** `TableSelectionCostModel` (28.3's frozen config-driven model) drops the two flat neighbor weights for a single `neighbor_base` plus `include_fuzzy_neighbors`. `select_schema_context`'s neighbor expansion multiplies `neighbor_base` by the relationship's `effective_confidence`. Confidence is the sole trust signal (no type-weight double-counting). Existing golden/benchmark fixtures are all explicit-FK (`confidence=None`→1.0 → `neighbor_base×1.0=20`=old weight), so they are behavior-preserving; the new capability is exercised by new tests on implicit-relationship schemas.

**Tech Stack:** Python 3.11 (CI)/3.12 (local), pydantic 2.13.4 (pinned), pytest. No new dependencies.

## Global Constraints

- **Purity preserved:** `table_selection_cost.py` and `schema_context_selector.py` stay stdlib+pydantic only. `cost_model` is injected; `probe` (28.1), `node_budget` (28.2), `cost_budget`/selection algorithm (28.3) behavior UNCHANGED. Confidence affects only neighbor **benefit** — NOT `table_cost` and NOT `find_join_paths`.
- **effective_confidence:** `rel.confidence if rel.confidence is not None else 1.0`. Explicit FKs and CUSTOM relationships have `confidence=None` → 1.0 (declared = certain).
- **Behavior-preserving on existing fixtures:** golden schema (all explicit, `confidence=None`) selects identically (`neighbor_base=20 × 1.0 = 20` = old `explicit_neighbor`). Golden eval MUST stay green with NO fixture curation. Benchmark `context_selection` metrics MUST be identical (synthetic schema is explicit-FK-only) → NO v5 bump expected; verify and only bump if they actually change.
- **from_config tolerance:** old configs carrying `explicit_neighbor`/`implicit_neighbor` keys are silently dropped (unknown-field filter); `include_fuzzy_neighbors` is a bool field (extend `from_config` beyond `_is_number`).
- **No Claude commit trailer**; plain ASCII; `§` only in prose.
- **Run tests from** `backend/`. Check the fastapi pin (`0.115.12`) before full-suite runs; restore if drifted.

```python
_KNOWN_BOOL_FIELDS = {"include_fuzzy_neighbors"}

def from_config(raw) -> TableSelectionCostModel:
    if not raw:
        return DEFAULT_COST_MODEL
    try:
        data = json.loads(raw)
    except (ValueError, TypeError):
        return DEFAULT_COST_MODEL
    if not isinstance(data, dict):
        return DEFAULT_COST_MODEL
    overrides = {}
    for k, v in data.items():
        if k in _KNOWN_FIELDS and _is_number(v):
            overrides[k] = float(v)
        elif k in _KNOWN_BOOL_FIELDS and isinstance(v, bool):
            overrides[k] = v
    return TableSelectionCostModel(**overrides)
```
Add the helper:
```python
def neighbor_benefit(rel_confidence, model: TableSelectionCostModel) -> float:
    """Neighbor relevance benefit = neighbor_base * effective_confidence.
    A relationship with confidence None (explicit FK / custom) is certain -> 1.0."""
    conf = rel_confidence if rel_confidence is not None else 1.0
    return model.neighbor_base * conf
```

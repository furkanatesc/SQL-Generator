# Schema Cache Invalidation (Sprint 28.6) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make `SchemaManager.load_schema` invalidate `schema_cache.json` automatically when its inputs change — a content fingerprint over `{SCHEMA_CACHE_VERSION, db_type, hidden_tables config, hidden_columns config, embedding_model}` replaces the ad-hoc `db_type`-only check, so config edits, embedding-model changes, and extraction-code bumps no longer serve a stale schema.

**Architecture:** A new pure `compute_cache_fingerprint` (stdlib `hashlib`) computes a deterministic SHA-256 over the invalidation-relevant inputs. `load_schema` (dirty) computes the current fingerprint (embedding model read cheaply from a side-effect-free `NVIDIAEmbeddingClient().model`), compares it to the cache's stored `cache_fingerprint`, and re-extracts on mismatch/missing. The `db_type` check is subsumed. Lock/stampede/deepcopy/RAG indexing are unchanged. Self-contained — no new DB query.

**Tech Stack:** Python 3.11 (CI)/3.12 (local), pydantic 2.13.4 (pinned), pytest, stdlib `hashlib`/`json`. No new dependencies. No benchmark impact (the benchmark uses `from_legacy_schema` on synthetic schemas, not `SchemaManager.load_schema`).

## Global Constraints

- **Pure fingerprint / dirty wiring:** `schema_cache_fingerprint.py` is stdlib-only, deterministic, no I/O. `load_schema` does the config/file I/O. (27.8/28.3 pure-leaf pattern.)
- **Preserved behavior:** `_schema_lock`, cache-stampede protection, `copy.deepcopy`, `schema["embeddings"]` attach, RAGManager indexing, the `embeddings is None → rebuild` re-trigger, and the explicit/custom/implicit relationship dressing (after line 533) are ALL unchanged. Only the cache read/write predicate + a stored fingerprint field change.
- **Embedding-model access is cheap:** `NVIDIAEmbeddingClient.__init__` only sets `base_url`/`model`/`api_key` (network + key resolution happen only in `get_embedding*`). Reading `.model` at fingerprint-time is safe.
- **Backward-compat:** an existing `schema_cache.json` with no `cache_fingerprint` key → `.get(...)` None → mismatch → one-time re-extract, then rewritten with a fingerprint.
- **No new dependency.** No Claude commit trailer; plain ASCII; `§` only in prose.
- **Run tests from** `backend/`. Check the fastapi pin (`0.115.12`) before full-suite runs; restore if drifted.

```python
"""Schema cache invalidation fingerprint — PURE (Sprint 28.6).

Deterministic SHA-256 over the inputs the cached schema depends on. Injected/
used by SchemaManager.load_schema (no I/O here). Bump SCHEMA_CACHE_VERSION when
the extraction logic or cache format changes to invalidate all existing caches.
"""
import hashlib

SCHEMA_CACHE_VERSION = "v1"

_SEP = "\x1f"  # unit separator — cannot collide with JSON config content


def compute_cache_fingerprint(*, db_type, hidden_tables_raw, hidden_columns_raw,
                              embedding_model, cache_version=SCHEMA_CACHE_VERSION) -> str:
    payload = _SEP.join([
        cache_version or "",
        db_type or "",
        hidden_tables_raw or "",
        hidden_columns_raw or "",
        embedding_model or "",
    ])
    return hashlib.sha256(payload.encode("utf-8")).hexdigest()
```

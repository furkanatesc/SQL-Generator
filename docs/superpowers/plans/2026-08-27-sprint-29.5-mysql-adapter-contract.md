## Global Constraints

- **Mirror the Oracle modules.** Each core file adapts its Oracle counterpart (`oracle_adapter.py` / `oracle_connection_resolver.py` / `oracle_execution_adapter.py` / `oracle_seed.py`) via a mechanical rename plus the named behavioral deltas. Read the Oracle file first; do not invent a new structure.
- **Mechanical rename map:** `Oracle`→`MySQL`, `oracle`→`mysql`, `ORACLE`→`MYSQL`, `oracledb`→`pymysql`, `service_name`→`database`, contract version `sql_oracle_adapter_contract_v1`→`sql_mysql_adapter_contract_v1`, capability flag `supports_oracle_execution`→`supports_mysql_execution`, dialect string `"oracle"`→`"mysql"`.
- **MySQL behavioral deltas (load-bearing):** read-only tx is `START TRANSACTION READ ONLY` (not `SET TRANSACTION READ ONLY`); statement timeout is `SET SESSION max_execution_time = <ms>` issued before the SELECT (not `conn.call_timeout`); the connection carries `database` (not `service_name`); `pymysql.connect(..., autocommit=False, read_timeout=<ceil(timeout_seconds)>)`. `_sanitize_mysql_error` maps a MySQL timeout (error code 3024 / `max_execution_time` exceeded, and client read-timeout) to a distinct message and otherwise returns `f"MySQL execution failed ({type(exc).__name__})."` — never leaking host/user/password/database.
- **Identifier case:** MySQL preserves identifier/alias case as written (Linux/Docker default). All seed tables/columns and all test SQL are lowercase; seeded-test column-key assertions use the alias case as written (lowercase) — NOT uppercase (this is the key difference from Oracle).
- **Driver isolation:** no module imports `pymysql` (or `mysqlclient`/`sqlalchemy`) at top level — `pymysql` imports lazily inside execution/`main()` paths only. Subprocess tests enforce this.
- **`__init__.py` exports:** export the `mysql_adapter` public surface from `app/evaluation/__init__.py` (mirroring how `oracle_adapter` is exported). Do NOT export `mysql_connection_resolver`, `mysql_execution_adapter`, or `mysql_seed` (harness-only, mirroring the Oracle precedent).
- **No new execution behavior in the shared contract** beyond adding the `MYSQL` enum member.
- **Commit messages:** plain, no Claude/co-author trailer. Prefixes `feat(29.5):` / `test(29.5):` / `ci(29.5):` / `docs(29.5):`.
- **Before running the full suite:** ensure venv `fastapi==0.115.12` (see memory `sqlgen-fastapi-pin-drift`) or the `api_surface` test fails spuriously.

# MySQL max_execution_time exceeded -> error code 3024; client read timeout -> 2013/timeout.
_MYSQL_TIMEOUT_CODES = (3024, 1969, 2013)


def _sanitize_mysql_error(exc: Exception) -> str:
    """Credential-free, deterministic message. Timeouts get a distinct message."""
    code = None
    try:
        code = exc.args[0]
    except (IndexError, AttributeError):
        code = None
    if isinstance(code, int) and code in _MYSQL_TIMEOUT_CODES:
        return "MySQL execution timed out (max_execution_time exceeded)."
    if "timed out" in str(exc).lower() or "timeout" in type(exc).__name__.lower():
        return "MySQL execution timed out (max_execution_time exceeded)."
    return f"MySQL execution failed ({type(exc).__name__})."
```

"""Sprint 29.5 — Pure local-Docker MySQL connection resolver.

Single, reusable place a SQLMySQLLocalDockerConnection is built from the
MYSQL_TEST_* env contract. Never connects and never raises: any invalid /
remote / missing value yields None (inert), matching the adapter's
connection=None inert path.
"""

import os
from typing import Mapping, Optional

from app.evaluation.mysql_adapter import (
    SQLMySQLAdapterContractError,
    SQLMySQLLocalDockerConnection,
)

MYSQL_CONNECTION_RESOLVER_VERSION = "v1"


def resolve_local_docker_connection(
    env: Optional[Mapping[str, str]] = None,
) -> Optional[SQLMySQLLocalDockerConnection]:
    src = os.environ if env is None else env
    host = src.get("MYSQL_TEST_HOST", "localhost")
    port_raw = src.get("MYSQL_TEST_PORT", "3306")
    database = src.get("MYSQL_TEST_DB", "sqlgen_test")
    user = src.get("MYSQL_TEST_USER", "sqlgen")
    password = src.get("MYSQL_TEST_PASSWORD", "sqlgen")

    try:
        port = int(port_raw)
    except (TypeError, ValueError):
        return None

    try:
        return SQLMySQLLocalDockerConnection(
            host=host, port=port, database=database, user=user, password=password,
        )
    except (SQLMySQLAdapterContractError, ValueError):
        return None
```

# PostgreSQL EXPLAIN-Only Mode Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** PostgreSQL için gerçek EXPLAIN(-only) execution path'i ekle — 25.8 adapter'a EXPLAIN/EXPLAIN ANALYZE, 29.1 execution adapter'a `EXPLAIN_ONLY` mode kabulü.

**Architecture:** İki katman, standalone/inert (29.1 deseni). Katman 1: 25.8 `postgres_adapter.py` `execution_mode="explain_only"` dalında `EXPLAIN <sql>` (opt-in `EXPLAIN (ANALYZE) <sql>`) çalıştırır; read-only gate iç SELECT üzerinde değişmeden kalır; EXPLAIN çıktısı tek-kolonlu `"QUERY PLAN"` result set'i olarak mevcut `rows`/`columns`/`fetchmany` plumbing'inden akar. Katman 2: 29.1 `postgres_execution_adapter.py` `EXPLAIN_ONLY` mode'unu kabul eder, `explain_analyze` flag'ini 25.8 config'e map'ler. Canlı HTTP pipeline'a wire edilmez.

**Tech Stack:** Python 3.12, pytest, psycopg2 (lazy/runtime-only), frozen dataclasses, PostgreSQL 16 (local Docker).

**Spec:** `docs/superpowers/specs/2026-08-14-sprint-29.2-postgres-explain-only-mode-design.md`

## Global Constraints

- **Local-Docker-only, read-only.** Uzak/production connection yok; host `localhost`/`127.0.0.1`/`::1`.
- **Driver-izole.** Modül import-time'da `psycopg2`/socket/network-client yüklemez; `import psycopg2` yalnız `_execute_select` içinde lazy.
- **Secret-free.** Sonuç yalnız `sql_sha256` + sanitize `execution_error` + kolon adları + satır değerleri taşır; host/user/password asla.
- **Determinizm.** Kod `datetime.now()`/rasgelelik kullanmaz; `duration_ms` monotonic. ANALYZE'ın gerçek-süre çıktısına **assert edilmez**.
- **Geriye uyumluluk.** Yeni config alanları default'lu (`explain_analyze: bool = False`); mevcut çağıranlar/testler kırılmaz.
- **`sql_sha256` her zaman kullanıcının orijinal `request.sql`'inin hash'idir** — EXPLAIN wrapper'ının değil.
- **Commit trailer yok** (düz mesaj; co-author / "Generated with" satırı yok).

```python
def _build_explain_sql(sql: str, analyze: bool) -> str:
    """Prefix a validated read-only SELECT with EXPLAIN (never runs writes).

    Strips trailing whitespace and a single trailing ``;`` so the EXPLAIN
    prefix composes cleanly. The inner ``sql`` has already passed the
    read-only SELECT gate; EXPLAIN is prepended to that safe statement.
    """
    inner = sql.rstrip()
    if inner.endswith(";"):
        inner = inner[:-1].rstrip()
    prefix = "EXPLAIN (ANALYZE) " if analyze else "EXPLAIN "
    return prefix + inner
```

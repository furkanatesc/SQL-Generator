generated SQL into top-level clauses with Turkish labels. No backend change (backend returns SQL-only).

- Deterministic, read-only, additive; no new deps; no runtime behavior change.
- Verify = build exit 0. Commit messages: plain, NO trailer / co-author / "Generated with".

---

### Task 1: `sqlExplain.ts` pure util

- [ ] **Step 1:** `ExplainClause { keyword; label; body }` + `explainSql(sql): ExplainClause[]`.
- [ ] **Step 2:** Single-pass scanner tracking paren `depth` and quote state (`'`/`"`); recognize clause keywords only at `depth===0` and outside quotes, at word boundaries. Multi-word keywords (GROUP BY, ORDER BY, *_JOIN, UNION ALL) matched before their single-word prefixes. Emit `{keyword,label,body}` per boundary; `body` = text up to next top-level keyword, trimmed. Empty/garbage → `[]`.
- [ ] **Step 3:** Turkish label map per spec §2.
